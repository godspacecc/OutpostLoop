# OutpostLoop Windows 可分发首版送审稿 v0.2

2026-11-12 · 整版待确认。拟交付 Windows 键鼠、一个河谷镇区域、两趟可完成的行动，以及经实际安装验证的安装包，由用户自行分发。已确认的[第一趟行动 v0.5](第一趟行动送审稿-v0.5.md)是本版的玩法基础，具体例外见本文。前期叙事依据已确认的[游戏总纲](游戏总纲.md)。v0.2 在 v0.1 的范围上补齐信息揭露顺序和验收。地图应用、第二趟行动、正式入口和安装包交付随本稿送审。

## 玩家会玩到什么

新玩家在镇口空手醒来，白天找水和食物，天黑前找一个能关门的房间。玩家可以把商铺后屋当基地，靠近物资但容易引来巡逻，也可以在住宅轮换落脚，省下加固材料。第三天带着剩余物资走到撤离点，第一次进入局外场所。系统展示这一趟的结果和已查明的路线，再给出一个能主动前往的目的地。第二趟返回河谷镇，让镇上的一条备用撤离路线重新可用。玩家可走较短的主街寻找零件，或沿水边绕开巡逻。完成修复后，亲自走过这条路并撤离，结算显示交付结果。

## 前期叙事与信息揭露

- **Boot 和新档开场**只呈现启动、进入游戏和眼前的生存处境。主角以为自己意外落到陌生地方，系统提供与水、食物、落脚、风险和本趟撤离有关的提示。穿越者身份、位面列表、多次出发、空间的真实身份与目的都留到相应剧情节点再揭露。
- **首次撤离**后才让玩家看见局外场所。系统先给出本趟结果。提前撤离只提供第一趟重试入口，成功达标撤离后，系统才给出一个具体的后续目的地和简报。由玩家发起第二次出发，在这里第一次实际看到系统可以安排后续行动。
- **第二趟行动**按系统给出的局部目标展开，任务简报和结算说明玩家要做什么、实际完成了什么。空间选择目的地的真实原因属于编剧背景。角色如何查出真相、如何打败空间留在后期剧情范围。

## 地图与首版内容量

- 一个河谷镇区域。以现有 2 × 2 公里外景为场景底稿，正式可玩路线集中在镇口、住宅后巷、临街商铺、仓储区与邻接的桥头通道。每处可进入、可搜、可落脚的地点由门、地形及提示明确表达。远处建筑作为地标和背景，玩法边界在地图上可读。
- 第一趟有 12 个搜点、两个可登记为基地的房间和一个撤离点。物资、装备、生命与生存规则沿用 v0.5。第二趟复用同一区域，启用不同的入口和撤离点，有 6 个搜点、一处可登记的房间和一个任务设施。
- 两类感染者共用巡逻、声响调查、追击和破门规则。首版只采用本文与 v0.5 所列的局内系统。科技树、其他世界与额外地图列为后续版本。

## 两趟行动和空间

### 第一趟 · 活下来并找到出口

按 v0.5 实施。每个游戏日 24 分钟，开局第 1 天 08:00，经过 72 分钟达成生存目标。第 67 分钟预告撤离，达标后有 2 分钟可在撤离点按 E。提前撤离、阵亡、窗口关闭各自显示原因。提前撤离也会首次见到空间，可以从空间重试第一趟。阵亡或超时直接进入失败结算，重试从镇口空手开始。只有达标后成功撤离，才解锁第二趟。

### 首次回归 · 选下一趟行动

撤离后进入一间可步行的小型空间，行动台是唯一功能点。用 E 查看本趟存活时长、结果、撤离时随身物品的快照及查明路线。物资、装备、基地和敌人状态留在当地。空间没有库存、收藏、货币或交易。成功记录解锁第二趟，已查明的住宅后巷和仓储通道在第二趟简报中标出。玩家可先退出游戏，之后从空间继续。

### 第二趟 · 打开桥头备用通道

- 从仓储区边缘空手落地，起始生命及生存状态与第一趟一致。现场时钟从 16:00 起，停留上限为 20 分钟，最后 5 分钟显示撤离预告。复用昼夜、身体状态、装备和施工中断规则。
- 两条到达桥头的路线分别经过临街商铺与河边后巷。每条路线各有 3 个搜点，共提供 2 份饮水、2 份食品、2 份绷带、1 根撬棍、1 支手电和 2 份维修零件。每条路线各保证一份水和一份维修零件，其他物资按种子重排。仓储边缘有一个可登记为基地的房间，可休息、存物和维修门扇。修门和修闸门消耗同一种零件。
- 桥头通道被卡死的手动闸门挡住。走到闸门侧按 E 检查，提示缺件或进入 10 秒维修。完工时扣 1 份维修零件并开启通道。操作产生施工声，普通与快速感染者沿用第一趟的声响与攻击规则。移动、受击或取消时终止维修，材料仍在背包。修好后同一闸门不能重复扣料，玩家能在地图和现场看到打开的路径。
- 穿过闸门，到对岸撤离点按 E 完成交付并回到空间。结算显示通道已开放、用时和本趟结果。阵亡、超时或在来路提前撤离都判第二趟未完成，保留第一趟的解锁。回空间可立即空手重试，重新生成种子。完成后行动台显示首版完成，可返回主菜单或重玩两趟。已完成标记保留，重玩仍新建局内状态。

## 操作、菜单与存档

| 场景 | 玩家操作与反馈 |
| --- | --- |
| 移动与交战 | WASD 移动，Shift 奔跑，鼠标瞄准，左键攻击，R 装填，F 开关手电。维持高位斜俯视跟随与近景遮挡处理。 |
| 现场和背包 | E 搜索、开关门、使用床铺、设立基地、修复任务闸门及撤离。V 打开当地基地入口的施工操作。Tab 开关背包，鼠标执行取放、装备和使用。世界交互显示当前对象、按键和失败原因。鼠标操作界面时屏蔽同次世界攻击。 |
| 暂停和结算 | Esc 先关闭当前面板，游戏中再次按 Esc 进入暂停。暂停冻结局时，可继续、保存返回主菜单或确认放弃本趟。睡眠用 E 提前起身。结算显示结果及下一步可用按钮。 |
| 开始界面 | 新行动、继续、设置、退出。继续进入活动行动或已保存的空间。新行动在已有进度时二次确认。设置提供分辨率、窗口模式、主音量和操作说明，随设置保存。 |
| 存档 | 一个本地档。行动内保存时保留 v0.5 规定的状态、种子、设施和当前任务进度。保存时先取消未完成操作，已完工状态保留。空间到达、第二趟解锁、完成和终局清理随对应结果一起写入。写盘失败保留上次有效档和当前可重试状态，界面给出提示。终局重复触发时，按阵亡、超时、撤离顺序结算一次。 |

## 正式表现与交付

- 采用已接受的高位斜俯视和写实方向。集中展示可玩的镇口、住宅/基地、商铺搜点、夜间手电、桥头和空间，以及角色、两类感染者、关键交互动画、HUD 和开始界面。按实际镜头展示，正式资产、动画和界面经用户确认后采用。实现阶段可先用临时表现验证玩法。
- 玩家应能从照明、脚步、施工、枪声、撞门和警报判断现场变化。受伤、缺水、满包、维修中断、暂停和撤离均有明确反馈。使用本项目独立资产及有分发权限的外部资源。
- 交付 Windows x64 单人离线安装包，随包附版本、键位、安装和存档说明。验证全新安装能启动、完成两趟、重启续档及正常退出。最终方案确认授权为实现和验证本版本所需的本地 Player Build、安装器生成及本地安装测试。分发由用户执行。

## 验收与开发顺序

| 里程碑 | 验收证据 |
| --- | --- |
| 第一趟完整行动 | 从 Boot 用键鼠开局，实际走完至少一趟 72 分钟行动。同种子对照设立基地与轮换落脚，第二种子复查物资可达。受控时钟覆盖提前撤离、失败、准时撤离、睡眠惊醒、基地失守和保存恢复。按 v0.5 复验背包、治疗、装填、掉落、手电、警报和维修。 |
| 回归与第二趟 | 第一趟提前撤离后能见空间并重试，达标后解锁第二趟。退出再启动可继续空间。第二趟按两条路线各走一次，至少覆盖维修中断不扣料、完成只扣一次、敌人调查施工声、过闸撤离、提前撤离与失败重试。核对跨趟无物资或装备继承。 |
| 前期叙事 | 用全新存档从 Boot 进入第一趟，核对开始页、开场、首趟提示、提前撤离与达标后的首次回归。首次主动出发选项在达标回归后才出现，第二趟简报说明本趟可观察的目标和结果。逐段检查玩家可见文字与画面，确保揭露顺序符合本稿。 |
| 正式场景与界面 | 完成集中实机预览评审。验证 1280×720 和 1920×1080 下的菜单、背包、交互提示、键鼠输入、暂停和回到主菜单。夜间对照白天检查可走路线、感染者和出口的辨识度。 |
| 安装包 | 在实际 Windows 环境使用安装器做干净安装，断网后从已安装程序启动，不依赖 Unity 编辑器。用键鼠从新档完成两趟，行动中和空间各退出重启一次。复核安装版存档、任务结果、设置、启动及退出日志，记录 Windows 版本、硬件、安装包版本和 SHA-256。 |
