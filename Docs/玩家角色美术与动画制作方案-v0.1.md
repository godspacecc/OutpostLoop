## 角色视觉提案

一句话：一个穿日常衣服、靠现场找到的物品求生的普通人，在俯视镜头下仍能看清朝向和正在做的事。

推荐短款日常外套、内搭、长裤和步行鞋。衣服轮廓简洁，有真实接缝、布料厚度与肘膝褶皱；磨损从袖口、膝部和鞋面出现，不默认全身破烂。开局不配置军用护甲、战术头盔、系统徽章或发光身体纹样。空间的真实身份不通过服装提前泄露。

外套建议灰蓝，内搭浅灰，长裤深灰，鞋底与局部缝线为低饱和暖色。上身与地面拉开明度，肩背、头部与手部形成稳定剪影；可交互提示仍由既有界面提供。夜间以实际照明验证，不用人物自发光代替夜间可读性。

| 尚待确定 | 推荐提案 | 可选做法与影响 |
| --- | --- | --- |
| 性别、年龄、面貌 | 先用无身份特征的人体比例与服装轮廓做比较预览，面部不定稿 | 指定具体外貌后可直接深化；多种可选角色会增加模型、服装适配和验收量 |
| 体型与比例 | 普通成年人体型，正常头身比；约 1.75 米仅作样片标尺 | 最终高度须与门、床、手持物和现有碰撞校准，不据此新增背景身份 |
| 初始衣着 | 灰蓝短外套、浅灰内搭、深灰裤、步行鞋 | 可改为更轻便的日常衬衫；肩背辨识度、布料厚度与剪影随之调整 |
| 可见背包 | 首轮造型比较先不带包，六格容量沿用现有规则 | 固定日常小包可作为服装表现候选，但需要单独确认，不能暗示开局已有物资或新增容量 |

首轮推荐集中比较服装剪影与配色；外貌未定不阻碍比例样片、手部挂点与动作技术验证。正式头部和衣装在造型预览确认后深化。

## 模型与道具规格提案

以下是单个玩家的首轮制作预算，属于待实测的上限建议，不代表已经测得性能。

| 项目 | 首轮目标 |
| --- | --- |
| 源文件与导出 | 保留可编辑建模文件；模型、骨骼与动画用 FBX 交换；Unity 2022.3.55f1c1 导入校准 |
| 单位与朝向 | Unity 中 1 单位为 1 米，脚底为角色基准；导出后检查正向、缩放为 1、挂点与根节点 |
| 网格 | 身体与衣装合计不超过 25,000 三角面；不含手持道具；先验证默认镜头收益再提高细节 |
| 材质与贴图 | 身体衣装最多 2 个材质槽，以 2K 贴图为起点；使用项目现有渲染管线支持的材质，不引入新的渲染管线 |
| 骨骼 | 人形骨架，建议不超过 80 根变形骨，每顶点最多 4 个骨骼影响；肩、肘、腕、髋、膝必须经弯曲检查 |
| 挂点 | 左右手、背部与腰侧预留；道具局部位置和旋转按配置校准，照明方向与实际瞄准一致 |
| 版本与命名 | 例如 CH_Player_Body_v001、AN_Player_Idle_v001、PR_Player_Crowbar_v001；交付时记录单位、版本和来源 |
| 源资源来源 | 独立制作或来源与授权清楚的素材；不复制其他项目人物或动画。外部素材采用前登记来源与许可 |

身体、衣服与手持物分离。首批道具为撬棍、手枪、手电、水瓶、食品包装和医疗用品的简化外形；只有实际装备或动作需要时显示。撬棍与手枪使用同一武器位，手电使用独立照明位；双手姿态必须验证手枪／撬棍与手电共存，不能因姿势冲突改变现有装备规则。

无需首版就制作表情系统、布料模拟或全套换装。LOD 是否制作在多人形同屏性能核对后决定；当前不把完整 LOD 系统作为玩家样片的前置工作。

## 动画清单与规则对应

表内时长来自已确认规则；没有既定时长的动作仅做视觉过渡，不添加等待、移动限制、无敌或伤害窗口。首批移动循环以当前实际位移速度驱动，避免脚滑。

| 编号 | 动作或组合 | 需要表现的内容 | 与规则的衔接 |
| --- | --- | --- | --- |
| PA-01 | 空手待机 | 呼吸、轻微重心移动；随朝向转身 | 不定时自动走动或触发声响 |
| PA-02 | 步行、奔跑、停步 | 空手移动循环，起停顺畅 | 读取实际速度；疲劳造成的降速沿用规则 |
| PA-03 | 持物待机与移动 | 撬棍、手枪、手电的上身姿态 | 与移动组合，不增加武器切换冷却 |
| PA-04 | 搜索与取物 | 按目标高度前伸、翻找、取回 | 显示实际交互状态；容器界面持续打开不等于持续翻找 |
| PA-05 | 撬棍近击 | 准备、挥击、收回；肢体有重量 | 兼容现有 0.8 秒攻击间隔与 1.5 米距离；伤害以领域判定为准 |
| PA-06 | 手枪瞄准与射击 | 手部持枪、短促后坐、回稳 | 实际开火事件触发表现；不额外扣弹或改变射线 |
| PA-07 | 装填 | 手部取弹与装填、复位 | 2.5 秒；完成时领域移入弹药，中断后回到正确姿态 |
| PA-08 | 手电开关与换电 | 手电随持物朝向、换电动作 | 换电 3 秒；亮灭和电量由实际装备状态驱动 |
| PA-09 | 饮水与进食 | 拿出、靠近口部、放下 | 饮水 2 秒，进食 4 秒；消耗仅在规则完成时发生 |
| PA-10 | 绷带与急救包 | 缠绕或检查伤处、收回用品 | 绷带 3 秒，急救包 6 秒；受击、移动、取消时清理道具 |
| PA-11 | 加固、维修、安装警报器 | 对入口进行可循环的手部作业 | 分别为 20／8／10 秒；使用循环段适配时长，不据动画帧扣料 |
| PA-12 | 入睡、睡眠循环、起身与惊醒 | 靠近床、躺下、安静循环、迅速起身 | 睡眠时世界继续；惊醒、敌人进入与受击沿用规则，不延迟交还控制 |
| PA-13 | 受击与倒地 | 短受击反应、生命归零后的倒地 | 不新增硬直或无敌；受击叠加不能使存活玩家失去既有操作能力 |
| PA-14 | 进出行动的姿态衔接 | 落地、撤离或回归时姿态复位 | 先使用现有流程过渡；具体剧情表演另行设计确认 |

PA 编号标识需求组，不代表每组只有一个动画文件。持枪、持撬棍、持手电组合要交付姿态覆盖表；首版可用上身叠加复用下肢循环。若目标高度或床位暂时无法对齐，记录限制并修正挂点或资产，不通过修改交互距离、床的位置或碰撞来掩盖问题。

## Unity 接入原则

领域层提供实际速度、朝向、装备、动作类型、进度、中断、受击和终局事实；表现层读取并驱动 Animator、道具挂点和视觉效果。动画事件只处理脚步、道具显隐等表现，不能决定伤害、补给、扣料或结算。

移动以现有领域位置为准，首轮动作使用原地动画，避免 Root Motion 改变走位、碰撞、射程或存档。进食、施工等按实际进度播放可循环动作，完成或打断立即转回合法姿态。暂停时表现跟随实际暂停状态；恢复后不补播重复完成事件。续玩从保存的领域状态重建姿态与道具，不另存一套冲突的动画时间轴。

正式接入前复审原型职责与配置：角色表现、动作映射和道具挂点从玩法控制代码中分离。当前文档不视为这一架构改造已经完成。

## 验收清单

- [ ] 比例预览能说明正侧背、空手状态、衣着与默认镜头下的头肩轮廓；记录外貌和衣着确认范围。
- [ ] 1280×720、1920×1080 同路线比较白天、阴雨与夜间；头手、武器方向和手电方向可辨，角色不会靠异常自发光照亮周边。
- [ ] 步行、奔跑、急停与改变方向时脚底无持续滑移；肩肘髋膝无明显塌陷、道具无严重穿模。
- [ ] 武器位为空／撬棍／手枪，分别结合照明位为空／手电，共六种组合核对待机、移动和交互退出。
- [ ] 饮食、治疗、装填、换电、施工完成与取消后的持物一致；重复输入不重复结算；装填、治疗至少各覆盖移动和受击打断。
- [ ] 睡眠起身和惊醒、暂停恢复、存档续玩、死亡结算和再次空手出发无遗留道具、播放或角色副本。
- [ ] 网格预算、材质槽、贴图、骨骼、授权来源和 Unity 导入检查均有记录。
- [ ] 技术测试采用变更实际涉及的非空测试类或完整方法，运行前声明范围与数量，保留通过明细；录屏与真人操作证据单列，不以截图代替动画质量验收。
