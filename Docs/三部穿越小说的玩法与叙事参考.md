# 三部穿越小说的玩法与叙事参考

2026-11-10 · 原文分析保留供研究。下文的原创情节候选（含《断线》）已被用户否决，当前设定见[游戏总纲](游戏总纲.md#已确认的游戏设定)。

## 原著设定与对 OutpostLoop 的启发

本节记录讨论中的原文依据与设计启发。先看一条规则能给玩家什么选择、怎样改变局内结果与跨局进度，再单独评估实现范围和代价。现有版本仅用于后续估算改动范围。OutpostLoop 的正式设定以游戏总纲为准。

### 《位面小蝴蝶》 · 征战空间

原著的征战空间是程攀用于培养新生代的高拟真虚拟世界。参与者在其中发展生产、组织军队和交战。每次行动有自己的胜负，失败后可以再次进入。

| 原著设定 | 对 OutpostLoop 的启发 |
| --- | --- |
| 《沉淀者》中，全海洋世界的参与者从人鱼形态起步，改走电池、电动力和水下武器路线。 | 世界条件要改变打法。地形、材料和技术条件影响基地选址、工事选择和防守方式。 |
| 《百分之九十八》中，陈轩的国家被摧毁后要从低技术时代重新发展，他用过的知识仍能在后续尝试中发挥作用。 | 研究和经验可以累积，每次行动仍要按当地条件采集、建设和布防。 |
| 《百分之九十八》中，陈轩多次失败仍可再进入。《有能力反抗吗？》中，达到相应时代和条件后，战果可以兑换局外奖励。 | 每局独立结算。成功回归能带回情报和研究，增加下一局的做法或开放新战区。失败后可以重开，角色阵亡与重开的剧情关系待定。 |

虚拟世界和训练体系属于原著背景。OutpostLoop 已确认由普通穿越者亲自进入正在交战的世界。

### 《井口战役》 · 第一个世界的梵西战役

任迪与其他新人被投进米亚那的远征军，开场便要带一支约八十人的连队。吉亚科莫率领米亚那一方与维努奇总督交战，当地各势力有自己的兵力、目标和立场。部分穿越者觉得这个世界像自己玩过的《国家崛起：传奇延续》，但各人记得的版本有差别。见《这个冷门的世界》《战役开始》《我是我，世界是世界》。

| 原著设定 | 对 OutpostLoop 的启发 |
| --- | --- |
| 战争早已发生，任迪作为当地军队里的一名指挥员参与其中。 | 先明确当地交战方在争什么，再确定玩家负责的行动。玩家可以打出具体战果，整场战争由各方共同推动。 |
| 《差异》《后勤》中，高气压和较低重力使飞艇适合运输。军队依靠飞艇补给，带停机高台的发电厂等设施便成了军事目标。 | 世界条件除了改变装备和打法，还能解释双方为什么争夺同一个地点。先明确当地怎么采运和补给，再推导哪里值得设防、敌人为什么来攻。 |
| 《炮兵的成长》《指挥与被指挥》中，任迪靠炮兵观察、组织火力和支援逐渐承担更大的任务。 | 用玩家能完成的行动来体现成长，例如从建起一个据点，到能在更困难的条件下守住它。 |

《位面小蝴蝶》说明世界条件怎样改变发展路线，梵西战役说明这些条件怎样进一步改变战争的争夺目标。

### 《井口战役》 · 下一次独立穿越，海宋位面

梵西战役之后还有同一世界的连环试炼。《清算》回述了其他新兵在那条连环试炼中的经历。任迪回到演变空间后，下一次独立进入的新世界从《抵达》开始。他以预备役身份参加赵卫国的晋级任务，进入约 1701 年的架空地球。早在六十多年前，另一批穿越者已经保住大明、建立海宋，并发展出跨洋贸易和蒸汽工业。任迪等人在这个格局下发展自己的根据地，经历与大明、海宋的战争，建立共和国。任务有二十年期限，建国后还要发展生产，离开前将政权交给当地人。见《抵达》《展开》《和平》《留遗产》《离开》。

| 原著设定 | 对 OutpostLoop 的启发 |
| --- | --- |
| 早期穿越者基本退场，他们留下的工业、运输和势力关系仍在运转。海宋的技术和生产基础也影响了大明的装备与军队。见《抵达》《破坏根基》。 | 前人的行动可以直接写进战场的初始状态。旧设施仍在、当地势力已经学会使用某种技术，都能让玩家读出世界有来历。 |
| 赵卫国用已有经验升级炉子，任迪的材料软化能力解决了加工难题。但到了大别山，枪和弹药能造出来，仍缺足够的人手。见《枪与弹》《天赋的用法》《谎言》。 | 每处战区都可以有不同的发展瓶颈。玩家要判断这局先解决物资、采运还是施工，再决定投入多少防御。 |
| 任迪想先拖住敌军发展，但大明调集了精锐主力。他面临转移保全兵力、放弃已有根据地，或留下应战的选择。见《破坏根基》。 | 当玩家的据点发展到足以妨碍敌方目标时，敌人有理由改变投入。可以借这个因果解释来袭升级，具体触发条件由玩法方案另定。 |
| 赵卫国起初猜测需要打倒海宋。到《和平》，队伍确认晋级主要看建国基础、资源和之后的和平发展，歼灭最强对手并非必要。 | 战斗可以服务于一个可检验的建设成果。玩家守住的是一个仍能运转的据点或设施，清敌是达成部分任务的手段。 |

海宋篇补充的是**战场怎样被前人改变，以及玩家守下来的东西能否继续发挥作用**。具体参战方、开战原因和剧情仍待后续确认。

### 海宋任务复核 · 演变空间怎样管一局

从规则角度看，海宋篇最接近游戏的是演变空间怎样处理出发资格、初始能力、任务判定和跨局结算。任务世界提供可用的条件和敌情，演变空间决定参与者能把哪些条件变成这次和下次行动的优势。

| 环节 | 演变空间的原文规则 | 对 OutpostLoop 的启发 |
| --- | --- | --- |
| 接受任务 | 海宋是赵卫国从少校晋级中校的任务。他用「繁荣丝结」带任迪等低军衔预备役进入。较早说明的通用规则还允许正式军官按军衔差下达计入预备役评价的任务。见《交钱》《见面》《抵达》《枪与弹》。 | 地图开放资格、任务目标和个人职责可以分别定义。单人版先用清楚的解锁条件和目标，原著的强制征召与上下级计分留作参考。 |
| 确认入场配置 | 任迪在投放前确认携带人员，按当时的上限带了三百名征召兵。赵卫国有生产基地勋章，任迪作为预备役没有。赵卫国投放的是火药时代的生产链，进入的却是已有蒸汽工业的任务世界。见《进入空间》《抵达》《枪与弹》。 | 把「已掌握的技术」「这一趟允许带什么」「当地条件能造什么」分开。地图门槛决定去不去得了，开局配置决定第一步怎么走，局内条件决定最终能做出什么。 |
| 局内权限与代价 | 演变在出发时要求对当地人保密；这也限制了军官揭露其他穿越者身份的做法。赵卫国仍可用当地生产条件改造勋章基地，但这次晋级失败会导致所用基地勋章报废。见《抵达》《枪与弹》《郁闷的赵卫国》《工业号角》。 | 系统限制只有改变玩家选择才值得做成玩法。例如限制开局补给，可以产生不同的开局打法。保密条款和押上已有资产在原著中有明确后果，在项目中属于待评估机制。 |
| 任务目标与回归 | 击败最强对手海宋并非赵卫国晋级的必要条件。任务更看重何时建立政权、资源和人口基础，以及之后的和平发展。海宋任务达到二十年期限后，任迪自动回归。见《和平》《离开》。 | 分开定义战场目标、开放回归的条件和强制结束的条件。限时守住、达标后自行回归、完成目标即结算，会给玩家不同的时间压力和继续作战的理由。 |
| 结算与下一次出发 | 回归后演变按任务指标、跨时代表现等评分，结算紫金、特殊道具和晋级资格。任迪可以选择何时接受晋级，晋级时机影响提前晋级带来的征召上限优势。他也把实际学到的工业知识用于训练下次出击的人员。见《收获》《连环触发》。 | 报酬、带回的研究和下一战区的进入资格分别结算。进度可以改变后续行动选项，不必折算为一个总分。 |

海宋任务值得研究的是**入场资格、开局配置、失败代价和结算奖励如何互相作用**。例如，同一场行动可以允许更强的开局配置，但要求玩家承担更大的失败损失。评估这条规则时，先看玩家会不会因为代价而改变选择，以及不同投入能否形成有意义的打法。

### 《井口战役》 · 元淼位面的连环触发任务

海宋之后，任迪和云辰和跟随正式上尉晓峰进入元淼位面。前一批人已经在这个世界做过任务，苍龙社要求本批守住基地和部队，接通下一批。下文以首次守备和后续接引为边界。见《连环触发》《问题重重》《防备》。

| 演变规则 | 原文依据 | 对 OutpostLoop 的启发 |
| --- | --- | --- |
| 达到最低标准即可接通后续任务 | 萧龙交代本段只需达到六十分，保住基地和部队即可触发后续。云辰和另有契约，触发成功后剩余次数清零。见《防备》。 | 将本局达标、解锁下一关和个人奖励分别判定。基础目标可以已经足够推进主线，额外目标给玩家继续打的理由。 |
| 位面决定系统允许采用哪种入场方式 | 演变在元淼允许征召兵直接生成、军官选择基地投放位置，并允许公开用天赋，但仍要求保密身份。海宋的人员和基地投放更隐蔽。见《抵达》《防备》。 | 同一个出发系统可以按战区配置不同权限，例如开局装备、能否呼叫补给、哪些设施可以就地建造。行动页提前显示条件。 |
| 同行人数占同一队的名额 | 预备役携带的兵占正式军官的配额。任迪虽然准备了更多征召兵，实际只带五百人，昂贵兵员的折损还会影响这次行动的收益。见《连环触发》《问题重重》《防备》。 | 让局外拥有量与单次入场上限分开。若以后增加开局配置，用一个共享配额就能形成采运与守备的取舍。 |
| 发任务的人也受系统约束 | 晓峰要求两人进攻兽人首都，演变判定极不合理，拒绝发布。改成劫掠补给的任务时，演变提示发布者要承担失败责任的七成。见《分道扬镳》。 | 用系统规则约束任务如何叠加。附加目标应说明代价，不能暗中修改已达成的基础目标。原著的上级指挥和责任比例属于研究参考。 |
| 已完成的任务与后续难度分开处理 | 任迪等人让战场发展远超预计，演变没有因此推翻既定评判。尉官完成触发后，演变调整后续阶段，加入休整期间的短期接引，并按新的战场情况改变能接任务的军衔范围。见《褪去的奇幻》《冷静的等待》《演变之内》《维稳—主导》。 | 本局达标后可以解锁另一套入场条件、敌情和目标。用结算标记切换预先配置的阶段就能表达接力，无须模拟两局之间的历史。 |

元淼篇值得研究的是**上一局的结果怎样改变下一局的规则**。单纯开放下一张地图，只检验玩家有没有通关。连环触发还可以让达标程度影响接下来的目标、入场权限或风险。评估时看玩家是否能理解不同结果的后果，以及这个差异会不会改变他在本局的选择。

### 《井口战役》 · 元淼后半段的分批任务与跨空间交战

本段继续分析同一元淼位面，从校官接引一直看到天云介入与战区重划。原著在同一个战场上给不同批次的穿越者分配不同目标、权限和结束条件。

| 机制 | 原文依据 | 设计启发与边界 |
| --- | --- | --- |
| 战场等级改变，任务随批次重新发放 | 元淼发展超出预估，演变把部分校官的任务缩成三个月生存，并限时询问上校是否承接后续。有人试图召兵获利而失败，也有人隐蔽到期。见《冷静的等待》《维稳—主导》《想一想》。 | 同一个战区可以有不同性质的行动。支援尚未到场时，低投入的生存任务奖励隐蔽和控制风险。长期部署任务才给扩张和投入重装备的理由。每一阶段的目标、准入条件和回归窗口应当在接取时交代清楚。 |
| 局外等级和当局权限各自判断 | 杨洋因主导程度和军衔不足而无法查询后续计划。任迪军衔虽低，却因主导元淼行动取得本场的最高权限。天云介入后，演变又提高前线参战者的知情权。见《临近结束》《道具形态》《天云vs演变》。 | 局外资历管接什么任务，局内行动可以解锁本场的情报与指挥权限。可考虑让侦察先打开敌军来路，再决定设防位置。胜负条件应在接任务时明确，敌军位置、数量和行动意图可以留给侦察。 |
| 同一战场的交战方可能各有结算逻辑 | 天云最初按小队互杀加减分，遭遇演变后改派任务。后来天云只规定队员被敌对穿越势力杀死会扣分，小队便自行杀掉新人以规避这条扣分条件。见《抹杀失效》《位面分离》。 | 先定义想鼓励的行为，再设结算指标。若要求玩家保护人员，应核算人员是否安全撤出。若要求守住设施，可以核算它在结算时是否仍能运转。敌方也可以有自己的行动目标，双方的胜负无需靠同一份杀敌计数决定。 |

本段最有价值的候选是**把任务条件按行动目的区分**。同一个敌强我弱的战区，若任务是活着带回情报，减少接敌就是有效打法。若任务是保住关键据点，就必须承担补给、防线和增援的压力。先看这两套规则能否让玩家作出不同决定，再独立评估内容与实现成本。

## 从原文提取的六个结构

### 1. 同去一个地方，各自有一笔账

《井口战役》里，晓峰要给自己的初始部队留出名额，任迪在意能带多少工程人才，云辰和则要用这次任务结清契约。《想一想》里，任迪以自由预备役身份提出平等合作，云辰和却在同一任务走到后段时宣布准备退役。同队、同一战场，并不会抹平各人的处境。 [《防备》](https://www.quanben.io/n/jingkouzhanyi/180.html) · [《想一想》](https://www.hetushu.com/book/3131/2217608.html)

**可写进故事。** 玩家可以是有权决定现场方案的外勤穿越者。同去的一名记录员想留下可以复查的资料，另一名维修员想尽快换回拖欠的器材。两个人都希望玩家活着回来，但对「这趟值不值得再留」意见不同。角色身份从他们各自要保住的东西写出来。

**可游戏化。** 出发前交代各方委托，结算按实际完成的任务写各自的回执。v0.10 已有基础、终极目标和研究带回，可以先用现有结果写回执。若委托改变奖励、出发条件或目标组合，则需要新增规则。

### 2. 下一批人进的是你改变过的地方

《井口战役》的连环任务把不同批次的穿越者放到同一历史的不同阶段。小基地由本地人逐步建成工业体系，后来的队伍面对的是已经被前一批人改变的世界。这个过程还有一层矛盾：本地人确实学会了生产，演变也借着他们的参与把外来干预藏进历史。 [《视角》](https://hetushu.com/book/3131/2217576.html) · [《人神对答》](https://www.8xiaoshuo.com/shu_195724/75344779.html)

**可写进故事。** 玩家接的是一次交接任务。上一班留下的设施还在运转，规程却已被当地人改过。出发前的档案记着设施原本用来做什么，到场后，玩家才发现现在靠它吃饭的是另一群人。

**可游戏化。** 先用固定的旧设施、标记和出发简报表现不同批次。程序种子负责这一趟的布局与威胁。同一地区若要保留前几局的建筑、破坏和阵营变化，就需要额外的世界存档与地图迁移规则，开发成本明显更高。

### 3. 成功做出来，和别人能照着做，是两件事

《位面小蝴蝶》的《水力，标准》写了木匠和铁匠共用量具，工匠能测量、复造并改良齿轮等零件。《井口战役》的《留遗产》也区分了核工业数据与具体操作中的细节，后者在当地人的生产中靠老手带新人传下去。两部作品里，知识是否留下，要看谁能接着做。 [《水力，标准》](https://www.hetubook.com/book/2595/1786709.html) · [《留遗产》](https://www.piaotia.com/html/8/8794/5670237.html)

**可写进故事。** 有人按旧图搭出过一套设备，但图纸只有尺寸，漏了工匠现场才知道的一步。玩家带回的成果可以是修正后的做法。在结算短文里，让下一班用它做成一件小事，交代这项研究为什么值钱。

**可游戏化。** 用「找到线索、现场实践、成功回归后才能沿用」表达这个过程，和现有采集、研究、交互与回归接近。若再要求图纸在不同地区使用不同材料或工艺，要另行设计替代配方和反馈。

### 4. 过去的经验在新环境里只有一半管用

《出笼记》的位面物理差异，要求穿越者先调查，再实验出当地能用的技术。潘多拉的水库沿用了水坝，却预留了下放拦截网的结构，应对当地的大型水生生物。外来者可以带来方法，环境仍决定哪种做法能用。 [《开笼，尽瞭》](https://www.piaotia.com/html/13/13508/9214271.html) · [《归来》](https://www.piaotia.com/html/13/13508/9286423.html)

**可写进故事。** 队里资历最浅的人未必懂机器，却最早注意到旧设备为什么会坏。一名对面来的维修员也可能比玩家更懂本地水土。把关键发现交给他们，穿越能力和经验就都有了边界。

**可游戏化。** 现有地形已能让相同工具有不同用途。开阔地的采运棚和狭窄山路上的拒马要求不同的布置。若新增每个世界独有的环境限制，应让限制在地图里看得见，并给玩家一种已有工具可用的解法。

### 5. 有机会回去时，才知道为什么想留下

《出笼记》的卫铿等到虫洞打开后主动延迟离开两百天。《留点什么》让他在决定如何留下成果前，先面对一个更小的难题：本地人愿意交易，却因为有人被扣留而不愿定居。卫铿考虑放人回家，好让他们自己决定是否再来。《位面小蝴蝶》则在《自己猜错自己》里反问程攀，和当地人并肩走对他自己有什么意义。 [《归来》](https://www.piaotia.com/html/13/13508/9286423.html) · [《留点什么》](https://www.piaotia.com/html/13/13508/9249580.html) · [《自己猜错自己》](https://www.piaotia.com/html/5/5671/4042500.html)

**可写进故事。** 把是否继续留在场上，与一个具体的人还在等什么连起来。撤回也有正当理由，例如把刚确认的险情带回去，下一班才不会误入。

**可游戏化。** v0.10 已有主动回归和达成终极目标后自动回归。基础结算写明及时带回了什么，终极结算写明多留那一段解决了什么。两个结果都能把这一趟讲完，重开时仍然是一个新局势。

### 6. 发任务的人和承担后果的人，可能有两种胜利

《井口战役》第一卷写任迪目睹己方获胜后的暴行。到《恐惧的未来》，一号把挑起战争、按死亡人数给分写成明文规则。《出笼记》的铁锈位面进一步把矛盾扩大到历史层面，外来的穿越者能反复挑选有利人物和结果，当地人的选择却被旧剧本压住。 [《我是我，世界是世界》](https://hetushu.com/book/3131/2217370.html) · [《恐惧的未来》](https://hetushu.com/book/3131/2218076.html) · [《牢笼》](https://www.piaotia.com/html/13/13508/11342618.html)

**可写进故事。** 同一场任务给两份结果。派遣方记设备和报告是否交回，当地人只关心那条路明天还能不能走。两份账都写实，不给玩家额外判道德分。

**可游戏化。** 先用已记录的任务结果写短结算。真正让两份账改变奖励或后续地图，需要另做规则与存档。把历史重演做成可操控系统还要解决跨局状态，适合留在背景设定里。

## 战争故事候选 · 断线

这场仗已经打了一个冬天。北军沿驿道推进，切断了河谷守军的补给，把一支守备队和伤员压在山脊另一侧。往常这片山地靠两条路调兵。一条是北军已经占领的大道，另一条是旧工坊背后的运料路。工坊撤守前放下了闸门，后来连绞盘也坏了。北军把营地扎在大道上，只派巡兵盯着山里。

战前，这个河谷的守军就和另一个世界有往来。大道失守后，河谷守军请对岸派几名能独立行动的外勤军官。玩家是其中一个，每次从故乡的安全派遣站进入战区，再由派遣站直接接回，交地图、图纸和军情。河谷守军和伤员仍靠本地道路进退。整条战线都在作战，玩家负责的是给山脊另一侧的守备队打开一条路。

**荒野是侦察战。** 玩家穿过北军巡逻区，利用手边的木石搭掩体和工事，先活下来，再找出哪段旧路能绕过大道。野外测绘一旦带回，后方就有了旧工坊的进场路线。遗迹勘察可补齐另一段旧路的情报。

**旧工坊是争夺通路。** 玩家在来敌的压力下取木轴、粗绳，修好绞盘，抬起封住运料路的木闸。开闸回报一送回去，指挥部才敢让人沿旧路去山口。多留一段临摹图纸，后方工兵就能照着制造备件，把刚抢通的路维持下去。

**山口是阵地防守。** 玩家点火，告诉山脊另一侧，接应的人已到。北军也看得见烟，立刻派巡兵试探，随后派跑手绕路，最后投入能拆拒马的攻坚兵。玩家守住烽火并击退三批来敌，就能带回敌军的进攻方向。若再登上高台升旗，山脊另一侧才知道这条路可以走，开始把伤员送下来。结算里可以写到第一副担架通过旧工坊闸门，交代守住山口换来了什么。

敌人有明确的军事目的。只要山路重新接通，北军就得分兵防备侧翼，大道上的封锁也失去作用。普通兵带队巡查和接战，快速兵走侧路，攻坚兵针对工事。造型可以从同一支军队的制服、旗号和装备演化，再用三种兵种轮廓区分。玩家这边的木桩拒马、绊索弩台和采运棚，都是一名缺乏后方支援的军官在敌前用当地材料搭起来的战地设施。

打通一段山路就能让这场行动有结局。新种子可以作为同类战区行动重玩，由新的出生点、资源和敌情决定打法。伤员接出可在现有升旗结果后的战报里交代。

## 选材与范围

现阶段最适合合在一起的是**不同人的任务、能交接的成果、可以主动回归**。三者都能通过现有目标和结果来表达。原著专名、人物、任务剧情、组织制度和奖励术语作为出处保留在研究文档中。原创故事各自重写穿越的原因、角色关系、冲突和结果。

重复游玩的单位是一次有交代的战地行动。同类任务可以在同一战区的不同落点发生，地图的资源、路径和敌情继续由种子决定。世界观解释为何还要出击，单局战报说明这一趟做到了什么。跨局地形继承、整套委托经济、派系自治和时间线重演均属于独立的后续玩法议题。
