# 玩家运动样片修复 · 2026-11-18

## 结论与范围

**基础人体、服装与待机／走／跑的本轮组装问题已修复，可以继续制作临时运动样片。** 原失败记录保留；本结论仅覆盖独立 Unity 验证项目，不代表正式造型、完整动作集或主游戏接入验收。

预览采用用户已有 Sunbox 角色及 Human Basic Motions 动作。红格衬衫、牛仔裤、运动鞋、男性人体均为技术展示，尚未确认采用。头发仍未通过定位验证，本轮画面暂不显示发型。

## 根因与修复

1. 原始 FBX 的层级、绑定变换不能替代原包 prefab 已配置骨架。读取原包 Avatar.prefab 与 AvatarCustomization 组装逻辑后，改为使用 prefab 中的 Male_Avatar 层级。
2. 原包服装使用网格与身体完整骨骼数组，不能只靠骨骼名称替换。按此方式重建三件衣装，复用身体根骨和统一绑定空间。
3. prefab 原有服装与新增服装同时显示会产生重叠和黑色斑片。清理旧服装渲染器，仅保留本批选取的衣装。
4. 使用同一中性形体参数，并按原包配置启用衬衫、长裤、鞋的身体隐藏 blend shape（索引 38、24、25），消除身体穿出衣服。
5. 保留 Kevin 动作包参考 Avatar 依赖。批量截帧在编辑器 Play 中驱动 Animator，再对当帧骨骼 BakeMesh 渲染，避免同步截帧延迟造成静态假象。

原包脚本仅用于阅读组装方法，未将其整套引入主项目。验证 prefab 未提供的组件移除后，仅用本批独立工具组装；主游戏源码、场景与依赖未修改。
