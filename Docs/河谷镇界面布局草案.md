# 河谷镇界面布局草案

2026-11-20 · 供评审 · 以现有河谷镇键鼠试玩和已确认的任务展示归属为基础。

打开任何界面，玩家先从位置、图标、数量和操作状态判断自己能做什么。说明集中在「操作与目标」，现场仅显示当前动作、必要状态和具有实际后果的提示。

## 局内布局

```text
┌─────────────────────────────────────────────────────┐
│ 生存状态、随身装备       当前目标             小地图 │
│                                                     │
│ 当前操作面板       角色、准星、道路与交互目标        │
│                                                     │
│ 暂停 · 帮助 · 地图      当前互动／动作进度           │
└─────────────────────────────────────────────────────┘
```

以 1280×720 为参考画布，中央留给人物、准星、门口和行车方向。左侧操作面板顶边接在生存状态下，双列面板先按样片的 600 宽校验，长列表在面板内部滚动。屏幕下缘由常用入口和一个当前互动共用。地图、暂停和结算在各自的全屏界面接收输入。触屏布局以后按对应版本的输入范围单独核对安全区和触点尺寸。

| 区域 | 功能 | 同时出现时 |
| --- | --- | --- |
| 左上 · 生存与装备 | 日时、生命、饮水、饱腹、精力、武器和弹药、手电、进入背包 | 驾驶时用当前操作行显示车速。受伤、出血等状态靠近生存数据。操作面板已显示容量时，HUD 的背包入口用短标签即可。 |
| 上方 · 目标和紧急状态 | 生存目标、撤离窗口、需及时处理的状态 | 平时显示短目标。撤离窗口、出血等具时效的状态优先。教程和操作详情由帮助入口承接。 |
| 右上 · 导航 | 小地图、当前位置、已知地标、撤离点 | 小地图与区域图使用相同标记语言。区域图打开时，地图画布优先，地标和比例尺留在图内。 |
| 左下方 · 当前操作面板 | 搜取、地面物品、储物、随身使用／装备、基地入口加固／维修／警报器 | 一次显示一个操作面板。搜取和储物共用双列，来源在左，背包在右。独立背包可用同一区域呈现已装备物品。基地操作随当前门口状态显示材料和动作。 |
| 底部 · 当前互动 | 搜索、交谈、上下车、休整、撤离 | 只保留当前目标的一项主操作及快捷键。进入搜取时把关闭放进面板。搜索和持续动作显示进度。 |
| 同一层的情报和对话 | 诊所交谈、仓库转运记录、现场反馈 | 简短交谈用当前互动附近的反馈位。转运记录作为搜点内容放在面板内，作为线索保留。受击和紧急状态优先于普通反馈。 |
| 全屏及弹窗 | 区域地图、暂停、帮助、设置、提早撤离确认、结算 | 同一时刻只有最前层接收输入。地图保留 M／Esc，关闭后回到既有行动状态。确认框先消费 Esc。继续、返回、重试的位置在同层保持一致。 |
| 编辑器工具 | 测试指令、日志和动态调试入口 | 评审正式 UI 时隐藏工具浮钮。调试窗口启用时独占其输入区域。 |

## 局外界面

| 阶段 | 页面分工 |
| --- | --- |
| 启动与进入地图 | Boot 和地图加载分别显示当前阶段及真实进度。加载失败的重试放在同一个反馈位置。 |
| 开始页 | 开始或继续、设置、退出及更新状态。 |
| 本趟结算 | 展示本趟结果、行动所得及回归入口，保存失败时就地重试。 |
| 空间与任务 | 首次行动结束后进入空间。为任务列表、详情、出发操作和历史行动结果安排页面位置。具体任务流程随任务方案确认。 |

## 组合校验

- **搜取／储物**：打开双列时仍看得到角色和箱子。满包看六格和按钮状态，能叠放的物品仍可捡。仓库线索在窄画面可读。
- **背包／基地入口**：从搜取切到使用或装备，再关闭回到行动。背包与加固、维修或警报器面板不叠放。
- **驾驶／地图**：驾驶时车速、道路和下车动作可同时辨认。打开地图后查看地标，返回后恢复原驾驶状态。
- **交谈／危急状态**：交谈内容、出血提示、撤离倒计时各有落点，普通反馈不会盖住必须立即处理的状态。
- **暂停／帮助／确认／结算**：核对 Esc、返回按钮和点击拦截，特别检查取消提前撤离和结算保存失败。
- 两种编辑器分辨率先跑以上组合，再检查长物品名和中英文按钮长度。空、满、禁用状态用文字或形状补充颜色。

本轮实现与截图覆盖搜取面板、容量与按钮状态，以及同屏目标卡和底栏的让位。其余功能按上表一起评审布局。
