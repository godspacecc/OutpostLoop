# OutpostLoop v0.8.1 触屏侦察

**2026-11-10 · 用户回复「可以」，确认本版方案**

本修订只补充 [v0.8 战争迷雾](战争迷雾-v0.8.md) 的纯触屏开局。玩家进入战场后，单指轻点远处地面，指挥员沿现有移动规则前往并揭开视野。发现矿点后，玩家从建造侧栏选择主基地，在合法格轻点落位。选址途中可以点「取消选址」，回到侦察状态。

| 场景 | 操作与结果 |
| --- | --- |
| 主基地未落位，未选中建造项 | 单指从主战场开始并在主战场抬起时，对点到的地面下达移动指令。黑区也可作为移动目标。开局提示显示「轻点地面，指挥员前往侦察」。 |
| 正在选址 | 单指抬起只提交选址，沿用视野、占地、资金和矿点条件。非法落位显示原因，保留选址，资金不变。点「取消选址」只退出预览，指挥员不会接到移动指令。 |
| 双指或 UI 操作 | 双指继续只做缩放，全部抬起前不产生单指指令。UI、小地图和状态栏不接收触屏侦察指令。暂停、升级、设置和结算均不下达战场指令。 |
| 主基地已落位 | 恢复现有触屏战场交互。键鼠继续沿用右键移动和左键选址。 |

确认后，从 Boot 使用纯触屏完成两种种子的侦察、合法落位和首座采集站建造。检查非法落位不扣费，取消不会派出指挥员，双指先后抬起不会误移动或落位。编辑器模拟触点和手机实机分别记录结果。建造、资金、视野半径和胜负沿用已确认的 v0.8 规则。
