## 探索与撤离 v0.2

2026-11-11 用户回复「可以」，确认先做空手落地、自由搜取、遇险和主动撤离的短试玩，试玩后再讨论建造和塔防。

**开局体验。** 主角是个普通人，意外落在陌生世界，开局空手，只能移动、观察和搜索。从安全落点立刻交还控制，默认镜头里有可搜索的路边箱、仓门和远处的灯。灯提供方向。玩家走近才认出灯旁的裂口能撤离。第一次活着撤离或阵亡后见到空间。空间只提供本趟结算和再次出发入口。

```text
                        [灯光 · 撤离点]
                         ↑         ↑
  [落点] → [路边箱] → [开阔道路]   [侧门]
              ↓                     ↑
           [仓门] → [低墙及巡逻] → [仓内物资]
```

仓门到侧门形成回路。巡逻区有可观察敌人和折返的遮挡点。道路提供基础收获和较短撤离路线。仓内零件有明确的带回价值，玩家可以在入口观察巡逻的空当，再决定走进去或沿原路折返。首轮使用同一张临时布局，灾变题材与正式场景后定。

| 系统 | 本阶段规则 |
| --- | --- |
| 移动与镜头 | WASD 直接移动，高位斜俯视镜头跟随。鼠标指向决定攻击方向。HUD 显示生命、背包和当前目标。探索场景保持固定镜头朝向，路线地标可对应。 |
| 查明与搜取 | 走近可搜物出现提示，按 E 完成一次短搜索，再从列表逐件取走。搜索前能看出容器可搜，搜索后才知道内容。离开或受击中断搜索，可回来重试。容器剩余物品留在原处。 |
| 背包 | 两个随身格。路边箱有一份补给，仓门外的工具架可搜到一根撬棍，仓内有一件带有和裂口对应异常标记的物品，成功撤离时在本趟结算中显示一条线索。每件占一格，满格时可在搜取界面放下现有物品再拾取。 |
| 遭遇 | 只有一个沿固定路线巡逻的敌人。发现主角后接近攻击，主角绕过遮挡并拉开距离后，敌人回到巡逻路线。拾取撬棍后可鼠标指向并左键近击，有出手间隔。玩家可以空手观察、等待和绕行，从侧门通过并撤离。 |
| 撤离 | 接近裂口后显示撤离提示，并在地图记住位置。按 E 或点击提示按钮主动撤离，结算仅显示撤离时随身携带的物品。空手也可撤离。首轮不显示全程倒计时，先验证玩家是否会主动收手。 |
| 阵亡和再出发 | 阵亡后结算本次损失，清空本次搜到的物品。下一次从空间主动出发，试玩复用同一地图布局，生成新的行动状态并空手落地。 |
| 输入与状态 | 搜取列表打开时，界面接收点击，角色不攻击。Esc 暂停并冻结巡逻与搜索。背包满、搜索中断、无交互目标及结算后重复请求均有明确反馈或保持终局状态。 |

**一趟实际走法。** 从落点拿到第一份补给。沿开阔路先认出撤离点，再折回仓门。玩家可以拿撬棍防身，也可以保留一个空格，等敌人走到另一侧后空手进仓带走线索。由侧门返回裂口并撤离。走短路线时可带着第一份补给直接离开。

**验收。** 从 Boot 用真实键鼠分别走通直接撤离、仓内搜取后撤离和阵亡回空间。核对未搜索前物品内容、背包满时的取舍、绕敌可达性、撤离结算仅属于本趟、阵亡清空本次内容和重开独立状态。观察试玩者能否根据地标认出下一步、解释什么时候愿意绕路，以及为何选择撤离。首轮只验探索与撤离。

| 结束和重开 | 走近撤离地标后按 E 或点击撤离。随身物品仅在本趟结算显示。阵亡失去本趟成果。再次出发空手落地，旧容器状态和搜索标记清空。空间只有结算和出发入口。 |
| 交付与验收 | Unity 编辑器可玩，采用临时写实表现。用两种确定的种子从 Boot 验证急救位置与零件位置变化。实景覆盖临街搜后撤离、空手穿仓库、拾取撬棍后近战、满包换物、使用急救包、受击和离开打断、空箱反馈、死亡与空手重开。确认至少两条可行路线，完整试玩能从地标和反馈辨认下一步。 |

首版画面用固定的阴天白昼。高位斜俯视保持街道、门洞、车辆和敌人轮廓清晰。废车是地标和搜索点。街区记录承担环境叙事，当前事件来自巡逻、搜索受击和撤离。生存压力来自三格生命、两格背包和两条路线的风险。近战沿用方向、距离、遮挡和出手间隔。

## 首次建造 v0.1

2026-11-11 用户选择「自己选位置」，采用本批自选落位方案。

本批只验证「亲自找到材料，自己挑地方建起第一座避难所」。沿用探索试玩的移动、搜索、危险和撤离。避难所的建设体验通过后，再设计围绕据点的袭击与防守。

**玩家走法。** 从路边箱搜到一份建材。沿开阔路走，能找到靠近补给的空地。绕到仓库侧门外，能找到遮挡较多的空地。玩家可以停在任一片空地附近，按 V 看避难所的占地预览，再选一个具体位置落位。建筑完成后，进入并交互可恢复一次生命。玩家可以继续去仓库探索，也可以立即前往撤离点。

| 项目 | 本批规则 |
| --- | --- |
| 入口与物资 | 从开始页进入「异界探索 · 撤离试玩」。角色空手落地。路边箱额外提供一份建材，建材占一个背包格，一份即可建避难所。先搜建材会少一个携带补给或装备的位置。 |
| 选址 | 地图加两块明显的可建空地。每块内都有多个具体落位可选。位置须在角色附近、可见且地面平整，避开道路、箱子、墙、撤离点和角色。未确认时显示占地与可建状态。 |
| 建造 | V 进入建造预览，鼠标定位、左键开工，右键或 Esc 取消。确认开工时扣建材，短工期后生效。材料不足、重叠或距离太远时给出原因，拒绝扣料。每趟最多一座，施工和完工期间不能重复下单。建造输入优先于攻击。 |
| 完工与回归 | 完工后可近距离按 E 使用一次，恢复一格生命。满血时提示并保留这次使用机会。暂停冻结工期，敌人继续使用原探索巡逻与追击规则。撤离或阵亡清理本趟工地和建筑。随身携带的建材在成功撤离时列入本趟结算。 |

**验收。** 从 Boot 搜得建材，用真实键鼠在两块空地分别预览并落位。核对无材料、非法占地、取消、重复下单、暂停施工及治疗使用边界。验证有据点和直接撤离两条路线均可完成，再出发时恢复空手、地图没有上局建筑。采用临时几何体。

## 第一次守据点 v0.2

2026-11-11 用户回复「可以」，确认按地图巡逻、施工调查和发现后交战的方式制作防守试玩。

**玩家走法。** 像现在一样搜建材、自选位置搭避难所。选址前可以观察道路和仓库附近的巡逻路线。路边开阔，巡逻者容易看见工地；侧门外有墙挡视线，但进出会经过仓库巡逻区。如果敌人听到附近施工，会离开原路线来查看。走到能看见避难所的位置才会攻击。玩家可以亲自应付，也可以搜来防守零件，在避难所旁自选位置安装一台自动防御装置。处理完威胁后可以继续搜索、回据点休整，或直接撤离。

| 项目 | 本批范围 |
| --- | --- |
| 材料和布防 | 原有建材用于避难所。仓门外箱增加一组防守零件，取走后占一个背包格。打开 V 建造菜单选择防御装置，使用原有占地预览及鼠标落位操作，短施工后完工。每趟一台。落位必须在据点附近的空地，位置会改变实际覆盖范围。预览显示射界，墙会阻挡射击。 |
| 威胁来源 | 地图开局就有仓库巡逻者和路边巡逻者各一名。施工只产生近距离声响，周围能听到的敌人会去查看。声响结束后，敌人找不到目标就回原路线。墙与货架遮挡视线，敌人行进沿现有可通行地形。保持距离、先清理附近敌人、选择遮挡和把握巡逻时机都会改变接敌结果。 |
| 防守过程 | 敌人确认目标后，靠近并攻击玩家或据点。界面显示敌人已注意到施工、正在接近或据点受击。防御装置仅自动攻击已发现玩家或据点、在射界内且无遮挡的敌人。玩家仍可用原有武器补防或撤离。避难所完工后可继续按原规则休整。 |
| 结束条件 | 玩家自行决定什么时候结束这一趟。避难所失守则失去休整与该处的防御能力，仍可带身上的物品撤离。活着撤离时结算列出随身物品，阵亡清空本趟物品。没有固定波次、清场门槛或额外杀敌奖励。暂停冻结施工与敌情，再出发重置。 |
| 边界与验收 | 从 Boot 验证三条路径：在开阔路旁施工引来巡逻者并用装置守住；在有遮挡的空地利用巡逻空当落位，施工完后仍可继续搜；被发现后弃守并活着撤离。补验墙阻挡自动攻击、建造无效不扣料、休整与结算。采用临时表现。 |

本批先验证「探索时看到的危险，是否会改变选址和布防」。

2026-11-11 用户回复「可以」，确认先做避难所仓储、外出搜维修材料、工作台加工与据点维修。

**玩家走法。** 带回第一批物资后，可以先存进避难所腾出背包，再出去搜下一处。附近还有少量维修材料，回到据点可以留着以后用，也可以交给工作台加工成一份维修件。遇袭后用它修避难所，为下一次外出留一个可以回来的地方。

| 环节 | 本批范围 |
| --- | --- |
| 储存 | 完工的避难所提供四格临时储存，靠近后用独立按钮打开。玩家用鼠标在背包与储存之间转移物品，容量满时不移动物品。原休整仍用 E。仓库内容在失守、阵亡和结算时清空，撤离结算只显示随身物品。 |
| 物资 | 新增一处可搜索的维修材料，单份占一格。它在仓库深处，玩家自己选择何时去取、拿回来或带走。防守零件继续专供防御装置。 |
| 工作台 | 避难所自带简易工作台。玩家放入材料并下单后，加工会自动完成，消耗一份维修材料，产出一份维修件。每趟最多一份。订单期间可出去探索。开始前确认仓库有产物位置；完工前预留该格。 |
| 维修与终局 | 维修件可以从仓库领走，也可在避难所旁用来恢复两格据点耐久，上限为满值。满耐久时不给扣料。失守后工作台不可用，未完工订单随据点清空；玩家仍可撤离。暂停冻结加工，重开新局恢复空手。 |
| 验收 | 从 Boot 搜物、存物、再次外出、启动加工，在据点受损后维修并撤离。对照提前撤离、满仓、满耐久、加工中失守、重复操作和重开。采用临时表现。 |

本批验证玩家是否愿意回据点存东西、腾出背包再走一趟，以及是否会权衡继续搜和保住据点。
