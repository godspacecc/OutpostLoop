# OutpostLoop 美术风格整理

## 2026-11-12 · 玩家进入游戏的空间体验

用户明确阶段含义。玩家启动游戏前身处现实，Boot 加载表现前往空间；开始界面就是空间；进入世界的加载界面表现从空间穿越至目的地。三阶段形成连续的进入体验。该要求定义玩家进入游戏的视觉流程，主角前期剧情仍以《游戏总纲》及后续确认的剧情为依据。

新候选采用同一空间的三个连续视点。Boot 从深蓝虚空接近浅色曲墙与悬浮顶板组成的场所，开始页停在场所内部，世界加载时镜头穿过前方逐渐显现目的地的界面。开始页的操作直接呈现在空间中。空间形制、材料、颜色、文字排布与穿越效果均待视觉评审。

候选图与生成提示词归档在 `Backup/Artifacts/SpaceEntryArt-20261112/`。图中的目的地仅为穿越效果示意。此次补充前生成的远景拼接开始页及六格分镜已作废。

## 2026-11-12 · 开场美术设计依据

用户明确要求独立设计游戏前面的美术。Boot、开始界面与穿越等阶段以《游戏总纲》已确认的世界观、前期叙事和本次美术要求为依据。当前项目已有的美术、玩法、地图、场景、UI、素材和实现状态均不构成本次设计约束。

从普通人意外进入异世界、跨世界行动、寻找归途，以及系统逐步显露穿越能力的体验出发，重新提出视觉主题、构图、配色、镜头和转场。既有试玩中的高位镜头、写实样片、镇口、三天生存、基地概念图和信标各自保留其历史适用范围；开场设计独立评审。

上一版六格分镜及对应提案按历史草案归档。其对现有信标、镇口和试玩表现的沿用依据已撤回，后续设计从本节原则重新展开。

## 2026-11-12 · Boot 信标确认状态纠正

用户明确信标主题尚未确认。执行总清单中原有的确认状态已纠正，现有 Boot 信标界面按待确认视觉记录。后续 Boot 美术重新提案。

本次开场分镜位于 `Backup/Artifacts/OpeningArt-20261112/opening-storyboard.png`。其中信标造型及整张分镜均为候选；先前提案中“延续已确认的信标主题”的表述已撤回。

## 2026-11-11 · 写实场景样片

用户确认以[写实概念预览](../Backup/Artifacts/RealisticShelterPreview-20261111/写实场景预览.png)的写实程度作为 Unity 实景样片的目标。保留高位斜俯视，以真实比例、阴天照明、表面磨损和实物构造表现角色、仓库与帆布避难所。首轮取景沿用探索试玩的道路、仓库入口、侧门与路边落脚点。

Unity MCP 已渲染[默认俯视](../Backup/Artifacts/RealisticShelterPreview-20261111/Unity-默认俯视.png)和[避难所近景](../Backup/Artifacts/RealisticShelterPreview-20261111/Unity-避难所近景.png)。采用独立预览场景、实物扫描材质和临时模型。当前可审材质方向、设施大小与路径识别。人物网格、衣物细节和仓库破损仍有待达到参考图的写实程度。正式资产采用和可玩地图接入待后续评审。

同批通过 Unity MCP 在编辑器 Play 会话中加载独立[可玩预览](../Backup/Artifacts/RealisticShelterPreview-20261111/可玩-完工.png)。复用现有地图通行、搜索、占地、施工和撤离规则，替换当前会话的地面、角色、箱子与避难所表现。脚本验证了搜取、扣料、施工、模型对位、撤离与重开。退出 Play 即恢复项目原有表现，正式素材仍待评审。

## 2026-11-11 · 末日世界美术研究

对应 [当前玩法方向](游戏总纲.md#2026-11-11-当前方向)。四类世界共享高位斜俯视和风格化写实 3D。每个世界先选一种灾前仍在运作的设施，再决定灾变破坏了什么、现场还在运转什么、幸存者改造了什么。首批样片和各世界的造型均为候选。

| 世界 | 高位镜头下的主要形状 | 可读的灾变痕迹和玩法提示 | 参考 |
| --- | --- | --- | --- |

| 核战后 · 城郊交通枢纽 | 倒塌的高架、露出骨架的楼、成片空地和掩体入口 | 用瓦砾堆与残墙表现爆炸后的破坏差异。防尘帘、拼接钢板和水箱标出幸存者活动。若有辐射玩法，用路标和仪表反馈表达范围 | [广岛市历史影像](https://peace-tourism.com/en/story/a-bombdome.html) · [Bethesda 的废土聚落参考](https://fallout.bethesda.net/en/games/fallout-4/your-journey-continues) |

默认镜头先读通路、敌人和关键物资。地面低对比处理，资源用轮廓和标记双重识别，工坊和炮塔从屋顶与装置外形区分。玩家据点用清楚的材料堆、运料路径和运行反馈表现从落脚到生产的变化。世界各自保留配色与材料，友方、威胁、交互和撤离使用一致的提示。

首张样片建议采用生化转运区。站台尽头的围栏缺口适合展示窄口营址，靠货箱的开敞集散场适合展示近料营址。同一画面核对人物、通路、可搜物资、避难所、炮塔和工坊在默认高位镜头下的辨识度。随后可用 AI 物流园作对照，验证灾变痕迹和机器轮廓能否让两个世界一眼可分。制作正式资源前先展示预览。

## 已确认的基础

- 高位斜俯视是已接受的概念方向。实景以现有透视镜头的默认取景、近景与全图为基准，造型要经得起镜头旋转。历史概念图的俯角用于参考构图。
- 基地概念图已确认用于开始界面，当前出发页将它标为「守城试玩 · 概念图」。画面中的金属基地、炮塔和发光晶矿归入守城概念参考。
- [v0.10 探索](探索战术扩展-v0.10.md)已确认低技术时代设定。荒野靠木石、绳索与草顶起步，旧工坊的设备上限是手摇绞盘，山口通过烽火和旗号传讯。三张图共享一套时代和材料体系。
- 现有场内地形、人物、建筑和任务点主要用临时几何体表达，HUD 与小地图承担文字及颜色识别。正式模型、动画及局内界面皮肤需分别展示对应实机场景，经用户明确确认后采用。所有新美术独立制作。

## 候选方向 · 手工拓荒

以旧概念图的高位构图、简洁块面和冷暖分区为参考。探索场景采用有重量感的风格化 3D，大形先行，近看才读到绳结、木纹和磨损。玩家从默认镜头看到的主要是物体的顶部和向镜头的一侧，角色肩背、建筑屋顶和装置顶部承担主要识别任务。

| 层级 | 表现提案 |
| --- | --- |
| 地面与障碍 | 灰绿、土褐、石灰色铺底，少量低对比细节。通路用连续的地表与清楚的边缘串起，可绕的岩石、封闭石墙和可通过的口子有各自的形状 |
| 人物与敌人 | 指挥员用短斗篷、背包和暖赭肩背识别。普通、快速、攻坚三类敌人先试直立、前倾、宽肩三种剪影，局内标记再强化区别 |
| 资源与目标 | 木料用并排原木截面，石料用成组碎块，纤维用捆扎轮廓。任务装置靠轮廓和简洁标记定位，火焰只出现在实际点火的物件上 |
| 建造 | 庇护所用宽草顶，采运棚用敞口与手推车，拒马用横向尖桩，弩台用张开的弩臂。木架、绳缚、石基贯穿四种建筑 |
| 界面与迷雾 | 延续 Boot 和出发页的深绿底与浅色文字。主操作、任务、敌情各有自己的形状或文字提示。保留未探索、已探索、当前可见三档，战场与小地图同步 |

## 第一张样片

建议选旧工坊。一个镜头里就能检查角色大小、木石材料、障碍与通路，以及关键机械是否符合时代。样片范围为闸门与绞盘、邻接石墙、木料棚与绳索棚、指挥员和当前任务 HUD。用同一种子、同一镜头并排记录现状和候选画面，展示闸门关闭与升起后的两种状态。

- 默认镜头下能辨认指挥员、绞盘、关闭的闸门和通往它的路径。近景能读出木轴、绳索与闸门之间的连接。
- 镜头旋转后，任务点与通路仍清楚。拉远时，关键标记维持可读，装饰细节让位于地形轮廓。
- 1280×720 与较窄横屏下，任务文字、小地图和触屏操作区留出足够的战场空间。迷雾覆盖后，任务与敌情的显示遵循现有可见性。
- 表现与当前占地、通行和任务状态对齐。样片通过实景预览确认后，再记录获准沿用的材料、轮廓、配色与界面规则，扩展到另外两张地图。
