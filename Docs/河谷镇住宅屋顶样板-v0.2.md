# 河谷镇住宅屋顶样板 v0.2

2026-11-21，用户回复「你直接开始做吧」，确认按本稿实施屋顶样板。

## 试玩流程

玩家进入现有两层住宅，从二楼沿有扶手的楼梯走到露天平屋顶。全程使用 WASD，可在楼梯中段停下或原路返回。屋顶边缘设实体矮墙，阻挡角色越出屋面。回到二楼时，镜头恢复室内遮挡。下雨时，屋顶和露天楼梯口可见雨效，屋檐下的室内仍有遮挡。

本批开放这一处屋顶，供步行和观察街区。掉落物按所在楼层保存和拾取，隔层交互和攻击沿用住宅样板的限制。感染者沿楼梯追击、跨楼层射击和从屋顶跳下另行评审。

新行动使用带屋顶的住宅。续玩仍按存档所属布局恢复，新档保存屋顶或楼梯上的实际位置。

## 验收

- 从 Boot 进入新行动，用 WASD 走通二楼到屋顶再返回，核对中途停步、折返、楼梯口和矮墙碰撞。
- 验证镜头升降和遮挡、屋顶雨效与二楼挡雨，以及屋顶掉落物的楼层隔离。
- 在屋顶和连接楼梯上保存并恢复，确认旧住宅样板档可按原位置续玩。
