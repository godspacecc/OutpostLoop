# OutpostLoop 游戏总纲

本纲记录已确认的世界观和游戏方向。制作具体内容时，以对应版本的确认范围为准。

## 2026-11-11 当前方向

一趟异世界行动由亲自探索与收集、选址建立基地、自动防守、经营生产与补给、撤离组成。玩家要在通行窗口关闭前完成一件能影响当地战局或灾情的事。遇到救援任务时，由玩家执行救援。

## 已确认的游戏设定

- **主角**起初是个普通人。故事从主角意外落在异世界开始。他与空间机缘巧合地相遇，首次行动结束后才见到空间的局外场所，并逐步学会主动出发。前期主角以为自己得到的只是一个普通系统，完全不知道它背后是一个位面生命。
- **空间的真实身份**是一个高等位面生命。它曾在位面争夺中失败，前期对主角及其行动的控制力因此受限。它不愿沦为低等生命，仍按自己的目标行动。前期它主动将自己包装成普通系统，向主角隐瞒身份与目的。
- **空间招募穿越者的目的**：它要借穿越者在各个位面中的行动争夺控制权，以此恢复实力。前期它提供求生支援，减少穿越者过早死亡，也会安排有难度的任务，让穿越者替它做事并在行动中得到训练。对空间来说，主角是可以替换的穿越者；失去一人后，它可以寻找下一人。
- **前期叙事**：玩家接触的游戏系统就是空间。前期的穿越（包括第一次投送）、目的地、求生目标和任务都由空间安排。第一次穿越在主角看来是一场意外，开场只呈现当下的求生处境，主角在后续行动中才逐步发现穿越可以主动发起、反复进行。空间通过开场叙事、系统提示、任务简报和结算，把自己包装成帮助主角生存和寻找归途的系统，借主角的行动推进自己的位面争夺。主角与玩家随剧情推进逐步发现真相。
- **空间的局外场所**是独立地点，承担接任务、出发和回归。主角逐步发现空间能帮助自己查看已查明的物资、规划避难所和发展科技。这个场所不能存放任何物资、装备或收藏。
- **主角与空间的关系**：前期双方互相利用。空间掌握跨位面路线，通过系统决定开放哪些任务、授予哪些权限以及如何结算，并借穿越者在位面中的行动推进自己的争夺计划。主角依靠系统提供的权限主动出发，希望借它掌握的路线找到回家的路。主角是否接受派遣，不决定空间的计划能否继续。后期主角得知真相，需要打败空间并取得对它的控制权。
- **目的地**是有明确历史的世界，可以处于革命战争、生化灾变、社会崩溃或核战后的阶段。战局或灾情带来短暂的通行窗口，局势重新稳定时必须撤离。
- **当地条件**决定可用的材料、设备和做法。玩家可以用掌握的技术配合当地材料和工艺建设。技术应影响选址、采运或防守，已验证的技术成果和情报可以用于后续行动。
- **行动成果**在当地发挥作用。玩家修建或守住的设施、交付的成果可以由当地组织继续使用。阵亡会失去本趟局内成果，玩家可以再次出发。

2026-11-12 · **前期叙事设定已确认。** 玩家先经历求生，首次行动结束后接触空间的局外场所，再逐步发现系统可以安排后续穿越。空间的真实身份、位面争夺与招募目的为编剧掌握的背景。后期已定主角最终打败并掌控空间的方向，发现真相和夺权的具体情节留待后期设计。

## 已确认的设计借鉴

- 《井口战役》的演变空间和无限流的主神空间，对应接任务、派遣和回归。
- 《井口战役》元淼篇的演变与天云，对应不同空间借穿越者争夺位面控制权的叙事结构。原著细节见[叙事参考](三部穿越小说的玩法与叙事参考.md#演变与天云争夺的是什么)。
- 《亿万僵尸》的发展基地和守潮，以及《红色警戒》的建造、生产和调度，对应基地建设与防守。
- 《逃离鸭科夫》的近距离角色取景，对应探索试玩的斜俯视跟随镜头。
