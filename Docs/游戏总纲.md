# OutpostLoop 游戏总纲

## 2026-11-11 当前方向

游戏的主干是一趟异世界行动。玩家前期亲自探索和收集，中期建立据点并用塔防保住人员、物资和生产，后期把重复劳动交给人手，自己决定产能、补给和防线优先级，最终在窗口关闭前撤离。小说设定为这个循环提供背景，当前开发优先验证玩法。

### 小说背景

- 玩家是普通人。故事从他意外落在异世界开始。首次行动结束后才见到空间，随后发现自己可以主动出发。
- 空间是主角的金手指。主角逐步发现自己能看见已查明的物资、规划避难所、发展科技，也可能在后续发现战场支援能力。能力从何而来、空间的完整历史和最终结局留待展开。
- 目的地必须有可定位的历史。战争与灾变带来短暂的通行窗口，局势重新稳定时必须撤离。主角出发前与目标历史没有联系，能否重访自己已介入的历史线待定。
- 活着返回才能带回本次成果。阵亡使玩家失去带入的装备和这趟的全部局内成果，空间里的自己和此前已带回的积累保留，仍可继续出发。
- 其他空间属于背景候选，可在后期彩蛋或联机时引入。

### 分阶段设计与验收

2026-11-11 复核。探索、塔防、经营是游戏的长期主干，当前先把探索和撤离设计完整，再提交这一阶段的实现范围。塔防和经营分别在进入对应阶段前补齐操作、规则、内容和验收。此前提出的一名工人是候选实现，移出当前开发范围。

| 阶段 | 先写清楚的玩家体验 | 通过后再推进 |
| --- | --- | --- |
| 探索与撤离 | 高位镜头怎么跟随、玩家如何移动和交互、落点与地标怎么布置、视野与物资怎么发现、携带和遇险如何取舍、撤离点怎么找到和使用、死亡与重开如何结算 | 从落地开始实测完整探索，覆盖活着撤离与阵亡回到空间。玩家能根据地图和提示自行走通 |
| 建造与防守 | 选址信息、建筑如何落位、防线怎么布置、敌人如何从地形进入、主角在交战时做什么 | 试玩两种选址，能解释各自的防守代价 |
| 经营 | 主角哪些事情仍亲自做、哪些重复操作可以减少、生产和补给怎样分配、成果如何结算 | 经营阶段有可观察的生产和分配决策，具体自动化方案在阶段设计中确定 |

探索阶段的第一版设计稿应包括一张路线草图和一段从开局到撤离的实际操作过程。草图标出落点、可辨认的地标、第一批物资、至少两条走法和撤离点。用同一张图核对镜头、寻路、搜取反馈、背包取舍和返回空间。建造、塔防、生产与工人系统均移出本阶段范围。

### 探索与撤离 v0.2

2026-11-11 用户回复「可以」，确认先做空手落地、自由搜取、遇险和主动撤离的短试玩，试玩后再讨论建造和塔防。

**开局体验。** 主角是个普通人，意外落在陌生世界，开局空手，只能移动、观察和搜索。从安全落点立刻交还控制，默认镜头里有可搜索的路边箱、仓门和远处的灯。灯提供方向。玩家走近才认出灯旁的裂口能撤离。第一次活着撤离或阵亡后见到空间。空间只有结算、已带回的物品和再次出发入口。

```text
                        [灯光 · 撤离点]
                         ↑         ↑
  [落点] → [路边箱] → [开阔道路]   [侧门]
              ↓                     ↑
           [仓门] → [低墙及巡逻] → [仓内物资]
```

仓门到侧门形成回路。巡逻区有可观察敌人和折返的遮挡点。道路提供基础收获和较短撤离路线。仓内零件有明确的带回价值，玩家可以在入口观察巡逻的空当，再决定走进去或沿原路折返。首轮使用同一张临时布局，灾变题材与正式场景后定。

| 系统 | 本阶段规则 |
| --- | --- |
| 移动与镜头 | WASD 直接移动，高位斜俯视镜头跟随。鼠标指向决定攻击方向。HUD 显示生命、背包和当前目标。探索场景保持固定镜头朝向，路线地标可对应。 |
| 查明与搜取 | 走近可搜物出现提示，按 E 完成一次短搜索，再从列表逐件取走。搜索前能看出容器可搜，搜索后才知道内容。离开或受击中断搜索，可回来重试。容器剩余物品留在原处。 |
| 背包 | 两个随身格。路边箱有一份补给，仓门外的工具架可搜到一根撬棍，仓内有一件带有和裂口对应异常标记的物品，带回后可在空间查阅一条线索。每件占一格，满格时可在搜取界面放下现有物品再拾取。空间里已结算的物品单独保存。 |
| 遭遇 | 只有一个沿固定路线巡逻的敌人。发现主角后接近攻击，主角绕过遮挡并拉开距离后，敌人回到巡逻路线。拾取撬棍后可鼠标指向并左键近击，有出手间隔。玩家可以空手观察、等待和绕行，从侧门通过并撤离。 |
| 撤离 | 接近裂口后显示撤离提示，并在地图记住位置。按 E 或点击提示按钮主动撤离，带回的物品按种类登记在空间收藏中。空手也可撤离。首轮不显示全程倒计时，先验证玩家是否会主动收手。 |
| 阵亡和再出发 | 阵亡后结算本次损失，清空本次搜到的物品。此前已结算的空间收藏保留。下一次从空间主动出发，试玩复用同一地图布局，生成新的行动状态并空手落地。 |
| 输入与状态 | 搜取列表打开时，界面接收点击，角色不攻击。Esc 暂停并冻结巡逻与搜索。背包满、搜索中断、无交互目标及结算后重复请求均有明确反馈或保持终局状态。 |

**一趟实际走法。** 从落点拿到第一份补给。沿开阔路先认出撤离点，再折回仓门。玩家可以拿撬棍防身，也可以保留一个空格，等敌人走到另一侧后空手进仓带走线索。由侧门返回裂口并撤离。走短路线时可带着第一份补给直接离开。

**验收。** 从 Boot 用真实键鼠分别走通直接撤离、仓内搜取后撤离和阵亡回空间。核对未搜索前物品内容、背包满时的取舍、绕敌可达性、撤离只入账一次、阵亡清空本次内容和重开独立状态。观察试玩者能否根据地标认出下一步、解释什么时候愿意绕路，以及为何选择撤离。首轮只验探索与撤离。

### 首次建造 v0.1

2026-11-11 用户选择「自己选位置」，采用本批自选落位方案。

本批只验证「亲自找到材料，自己挑地方建起第一座避难所」。沿用探索试玩的移动、搜索、危险和撤离。避难所的建设体验通过后，再设计围绕据点的袭击与防守。

**玩家走法。** 从路边箱搜到一份建材。沿开阔路走，能找到靠近补给的空地。绕到仓库侧门外，能找到遮挡较多的空地。玩家可以停在任一片空地附近，按 V 看避难所的占地预览，再选一个具体位置落位。建筑完成后，进入并交互可恢复一次生命。玩家可以继续去仓库探索，也可以立即前往撤离点。

| 项目 | 本批规则 |
| --- | --- |
| 入口与物资 | 从开始页进入「异界探索 · 撤离试玩」。角色空手落地。路边箱额外提供一份建材，建材占一个背包格，一份即可建避难所。先搜建材会少一个携带补给或装备的位置。 |
| 选址 | 地图加两块明显的可建空地。每块内都有多个具体落位可选。位置须在角色附近、可见且地面平整，避开道路、箱子、墙、撤离点和角色。未确认时显示占地与可建状态。 |
| 建造 | V 进入建造预览，鼠标定位、左键开工，右键或 Esc 取消。确认开工时扣建材，短工期后生效。材料不足、重叠或距离太远时给出原因，拒绝扣料。每趟最多一座，施工和完工期间不能重复下单。建造输入优先于攻击。 |
| 完工与回归 | 完工后可近距离按 E 使用一次，恢复一格生命。满血时提示并保留这次使用机会。暂停冻结工期，敌人继续使用原探索巡逻与追击规则。撤离或阵亡清理本趟工地和建筑。成功撤离时，未使用的建材可像普通物品一样登记在空间。 |

**验收。** 从 Boot 搜得建材，用真实键鼠在两块空地分别预览并落位。核对无材料、非法占地、取消、重复下单、暂停施工及治疗使用边界。验证有据点和直接撤离两条路线均可完成，再出发时恢复空手、地图没有上局建筑。采用临时几何体。

### 第一次守据点 v0.2

2026-11-11 用户回复「可以」，确认按地图巡逻、施工调查和发现后交战的方式制作防守试玩。

**玩家走法。** 像现在一样搜建材、自选位置搭避难所。选址前可以观察道路和仓库附近的巡逻路线。路边开阔，巡逻者容易看见工地；侧门外有墙挡视线，但进出会经过仓库巡逻区。如果敌人听到附近施工，会离开原路线来查看。走到能看见避难所的位置才会攻击。玩家可以亲自应付，也可以搜来防守零件，在避难所旁自选位置安装一台自动防御装置。处理完威胁后可以继续搜索、回据点休整，或直接撤离。

| 项目 | 本批范围 |
| --- | --- |
| 材料和布防 | 原有建材用于避难所。仓门外箱增加一组防守零件，取走后占一个背包格。打开 V 建造菜单选择防御装置，使用原有占地预览及鼠标落位操作，短施工后完工。每趟一台。落位必须在据点附近的空地，位置会改变实际覆盖范围。预览显示射界，墙会阻挡射击。 |
| 威胁来源 | 地图开局就有仓库巡逻者和路边巡逻者各一名。施工只产生近距离声响，周围能听到的敌人会去查看。声响结束后，敌人找不到目标就回原路线。墙与货架遮挡视线，敌人行进沿现有可通行地形。保持距离、先清理附近敌人、选择遮挡和把握巡逻时机都会改变接敌结果。 |
| 防守过程 | 敌人确认目标后，靠近并攻击玩家或据点。界面显示敌人已注意到施工、正在接近或据点受击。防御装置仅自动攻击已发现玩家或据点、在射界内且无遮挡的敌人。玩家仍可用原有武器补防或撤离。避难所完工后可继续按原规则休整。 |
| 结束条件 | 玩家自行决定什么时候结束这一趟。避难所失守则失去休整与该处的防御能力，仍可带身上的物品撤离。活着撤离按原规则登记随身物品，阵亡清空本趟物品。没有固定波次、清场门槛或额外杀敌奖励。暂停冻结施工与敌情，再出发重置。 |
| 边界与验收 | 从 Boot 验证三条路径：在开阔路旁施工引来巡逻者并用装置守住；在有遮挡的空地利用巡逻空当落位，施工完后仍可继续搜；被发现后弃守并活着撤离。补验墙阻挡自动攻击、建造无效不扣料、休整与结算。采用临时表现。 |

本批先验证「探索时看到的危险，是否会改变选址和布防」。

### 据点仓储与维修 v0.1（候选）

**玩家走法。** 带回第一批物资后，可以先存进避难所腾出背包，再出去搜下一处。附近还有少量维修材料，回到据点可以留着以后用，也可以交给工作台加工成一份维修件。遇袭后用它修避难所，为下一次外出留一个可以回来的地方。

| 环节 | 本批范围 |
| --- | --- |
| 储存 | 完工的避难所提供四格临时储存，靠近后用独立按钮打开。玩家用鼠标在背包与储存之间转移物品，容量满时不移动物品。原休整仍用 E。仓库内容在失守、阵亡和结算时清空，撤离只登记随身带走的东西。 |
| 物资 | 新增一处可搜索的维修材料，单份占一格。它在仓库深处，玩家自己选择何时去取、拿回来或带走。防守零件继续专供防御装置。 |
| 工作台 | 避难所自带简易工作台。玩家放入材料并下单后，加工会自动完成，消耗一份维修材料，产出一份维修件。每趟最多一份。订单期间可出去探索。开始前确认仓库有产物位置；完工前预留该格。 |
| 维修与终局 | 维修件可以从仓库领走，也可在避难所旁用来恢复两格据点耐久，上限为满值。满耐久时不给扣料。失守后工作台不可用，未完工订单随据点清空；玩家仍可撤离。暂停冻结加工，重开新局恢复空手。 |
| 验收 | 从 Boot 搜物、存物、再次外出、启动加工，在据点受损后维修并撤离。对照提前撤离、满仓、满耐久、加工中失守、重复操作和重开。采用临时表现。 |

本批验证玩家是否愿意回据点存东西、腾出背包再走一趟，以及是否会权衡继续搜和保住据点。

### 生化转运区 · 完整玩法切片 v0.3（历史候选）

以下保留供设计讨论查阅。具体范围以分阶段提交并经确认的方案为准。

**玩家体验。** 独自落在一张有两处可选营址的地图，亲自摸到第一批物资。近料营址容易开工，但要防两个方向。窄口营址只需守一路，但首趟运料更远。玩家建起避难所后启用一名工人，给他指定补给路线，自己决定先修炮塔还是先开工坊。第一轮袭击会打到实际选址的防线。玩家稳住据点后，把工人送回的材料交给工坊，产出一份可撤离的工艺成果，再亲自赶到撤离点。

#### 行动规则

| 环节 | 规则与范围 |
| --- | --- |
| 开局与探索 | 从 Boot 的试玩入口进入一张固定布局的临时地图，普通角色带一件本趟发放的采集工具独自落地。地图有两个营址、两类资源（建材和零件）、一个撤离点。玩家直接控制角色移动，靠近后交互收集，背包有容量限制。物资经过现场查明才显示类别与存量。 |
| 建造与用工 | 可建避难所、自动炮塔和工坊，各限一座。避难所建好后解锁一名工人和据点库存。角色卸货后，工人和建造使用同一库存。建造前预览位置、材料和用途，确认开工时扣料，完工才生效。工人接受玩家指定的资源点，自动采集、运回和卸货。 |
| 防守与经营 | 避难所建成后开始袭击，第一轮留出准备时间，之后按间隔继续至结算。敌人沿可通行路线向据点推进，炮塔自动攻击。工人受威胁会暂停运输并回撤，线路恢复安全后继续。玩家可以改派资源点，以及决定零件优先用于防御修理还是工坊产出。工坊在材料齐备且玩家下单后消耗材料，完工产出一份工艺成果。 |
| 撤离与失败 | 从落地开始有有限行动时间。玩家可以提前到撤离点确认离开。工艺完工后由玩家领入背包，随身带回计为达成本趟目标。未带回工艺则按提前撤离结算，本趟携带的普通物资在结算界面列出，试玩的跨局进度只记录工艺。阵亡或窗口关闭仍在场时按行动失败结算，清空本趟物资和成果。避难所失守后丧失生产和存储功能，角色仍可带着身上的东西撤离。 |
| 结算与再出发 | 三种结果都回到简化的空间界面。成功带回的工艺只入账一次，在界面可见，供下一次出发使用。试玩中这项工艺使下一趟工坊少消耗一个零件。失败保留空间里已有的成果。玩家可再次进入同一试玩布局，每次生成一份独立的行动状态，正式剧情中的历史线重访规则另定。 |
| 操作与异常 | 键鼠直接移动角色，靠近资源或撤离点按交互键。建造菜单选建筑并在地图落位，据点面板负责工人改派、修理和工坊下单。暂停冻结行动时间、袭击与生产。位置非法、库存不足、订单重复和结算后输入均拒绝执行并给出反馈。 |

行动时间从落地开始显示，首次发现撤离点后在地图上保留位置。建造中的设施、修理成本和工坊订单各自显示当前状态。工人回撤、资源耗尽或道路被阻断时，提示原因，并允许玩家改派已查明的资源点。具体工期、袭击间隔、资源量和窗口长度在试玩中调节。两种营址均须留出完成目标和撤离的时间，开局搜枪和搜背带均可跳过。

#### 实施与验收

1. **探索与撤离。** 先打通 Boot → 移动和查明物资 → 采集 → 撤离或阵亡 → 空间结算 → 再出发。建立局内状态与空间进度之间的保存边界。制作搜取和携带入口。
2. **选址与防守。** 接入避难所、地形通行、个人武器、炮塔和袭击，验证两个营址带来的防守取舍，以及个人自卫和据点防守各自能解决的问题。
3. **委派与经营。** 接入工人、库存、修理、工坊和跨局工艺效果。用完整任务引导串起前两批，验证玩家能把重复运输交给工人，亲自处理采运风险和投入优先级。

**整局验收。** 从 Boot 用两个营址分别完成「亲自采集 → 建造 → 扛过一次袭击 → 工人运回物资 → 工坊产出 → 活着撤离」，记录选址造成的运输时间、防线压力和投入差异。再覆盖提前撤离、带入后阵亡、超时、据点失守、重复结算与重开，核对局内清理和空间已有成果。完成一轮真实键鼠试玩，观察玩家能否发现材料、改派工人、找到撤离点，并在第二趟看见工艺的实际作用。采用临时表现。

完整剧情、更多世界、战场支援、联机和正式视觉在后续评估。v0.3 汇总前两版候选。

#### 首图任务与内容

玩家从一个临时转运站附近醒来。站里原本负责疏散和物资转运，封锁后仍留有建材、备件和维修记录。最初只提示找物资和撤离点。发现维修记录后，显示工艺目标和所需设施。任务提示跟随已完成的行动更新，玩家可以先选址或先搜物资，也可随时提前撤离。

| 任务阶段 | 玩家目标与完成条件 |
| --- | --- |
| 探路 | 找到撤离点并查明一个资源点。可直接撤离，也可沿近处的货场搜建材，或绕到站务间搜零件和防卫物资。 |
| 落脚 | 自选营址，收集并投入建材完成避难所。附近一名愿意帮忙的幸存者在避难所完工后加入，承担采运。 |
| 维持前哨 | 分配工人的采运路线，挡住开始逼近避难所的感染者。玩家可以用个人武器清理落单敌人和保护运料，或投入材料建炮塔，腾出时间生产和探索。 |
| 带回工艺 | 在工坊复现一份转运站的通用配件加工工艺，完成后随身携带至撤离点。成功带回后，下一趟工坊使用这项工艺可少消耗一个零件。 |

| 内容 | 首批候选 | 对玩法的作用 |
| --- | --- | --- |
| 建造资源 | 建材、零件 | 建材承担避难所、炮塔和工坊的主体成本。零件用于炮塔建设与修理，也用于工坊产出。修防线会挤占本趟的生产预算。 |
| 个人武器 | 初始撬棍、可搜到的一把手枪、有限弹药 | 撬棍兼作采集工具和近战自卫。手枪可从安全距离清开一段路，弹药需要搜索且只能在本趟使用。玩家要判断这几发是用来打开资源点，还是留到回防和撤离。 |
| 携带装备 | 初始背包、一件可搜到的搬运背带 | 背带增加建材和零件的携带量，影响玩家开工前要亲自跑几趟。角色靠近后交互拾取物品，手枪随身占一格背包，背带拾取即穿戴且只生效一次。 |
| 建筑 | 避难所、自动炮塔、工坊，各一座 | 避难所提供公共库存和用工入口，炮塔自动防御，工坊把库存变成可带回的科技成果。炮塔位置影响它能否同时保护据点和运料路线。 |

**操作与结算补充。** 鼠标指向敌人后左键攻击，数字键切换武器，靠近后按交互键拾取。近战需要进入攻击范围，手枪命中判定按瞄准方向，开火扣除一发弹药。弹药耗尽时提示并拒绝射击。建造预览与操作面板优先接收输入，确认落位和点按钮时不会攻击。武器、弹药和搬运装备属于本趟试用品，撤离时列出，工艺是首批唯一跨局成果。

**任务内容验收。** 核对玩家能从场景和目标提示找到物资与撤离点。用近料营址先布防、窄口营址先发展工坊各走一趟，记录搬运次数、个人武器使用时机和零件投入。补验错过手枪仍能完成任务、弹药耗尽可用撬棍、背带只增加一次容量，以及工艺留在工坊时撤离无法获得跨局进度。各世界的专属武器、防护装备、额外建造和多任务分支在本切片验收后再定。

## 既有原型与历史方案

本项目是一款高位斜俯视的轻量即时战略守城游戏。玩家从一名指挥员和局外资金起步，自选地点建立基地，再用建筑生产采集员和守军。采集员自动采运，守军和炮塔自动交战。守住主基地并消灭最后一波敌人即可结算，新局使用新种子。

首个完整可玩版以[已确认的 v0.7 玩法设计](首版玩法设计.md)为准。下方原型基线用于试玩对照，实施状态以执行总清单为准。

## 已确认的游戏设定

2026-11-10，用户确认以下简版大纲。

- 玩家是众多普通穿越者之一，亲自往返于安全的出发地和正在打仗的世界，在当地采集、建设和作战。
- 玩家平时生活在类似《井口战役》演变空间的独立局外空间，从那里接任务、出发并回归。此项由用户于 2026-11-10 补充。
- 2026-11-10 补充方向。局外空间类似无限流的主神空间，持续向多个处于灾变中的真实世界派遣人员。世界的变动为穿越和介入提供窗口，稳定世界通常难以派人或大幅干预。准入细节和首版可玩范围见当前送审稿。
- 各世界的地形、材料和技术条件不同，可用装备和打法随当地条件而变。
- 2026-11-10 确认多种灾变世界的方向。目的地可以是革命战争、生化灾变、社会崩溃后的末日或核战后世界。灾变局势提供派遣窗口，具体任务须指向玩家能改变的战局或灾情。
- 玩家可带自己的科技进入战区，包括图纸和少量关键设备，并用当地材料和工艺建设。局外技术选择应改变选址、采运或防守，现场验证的成果可带回并用于后续世界。
- 单局围绕战斗中的前哨建设和防守展开。每次行动解决一项足以影响当地局势的关键问题，战果可以接力，当地组织能继续使用交付成果。
- 完成任务后可以安全回归，将带回的情报和研究用于下一次行动。失败后重开属于游戏规则，故事层面的死亡与重开关系待定。

参战方、参战原因、穿越的具体机制和剧情留待后续确认。历史故事稿已否决，只保留作过程记录。

## 方向与设计约束

- **已确认的方向**借鉴《亿万僵尸》的发展基地和守潮目标，以及《红色警戒》的建造、生产和调度。玩家以少量指令作出策略决定，单位负责执行细节。
- **当前原型基线**采用 12 分钟、六波、有限地图与四向防线。这个基线用于比较每次试玩结果。数值和内容数量可在有证据时调整。
- **首个玩法里程碑**是一张地图上一局能玩出不同打法。优先经济和优先防御都应有可行路径，也应在中盘面对不同的资源或防线压力。
- 单局地图、设施和敌人规模有上限。跨局胜场解锁下一局的起始资金档位，起始资金最高 1,000。玩家在新地图重新选择基地、资源和防线。
- 首版验收在 Unity 编辑器完成。正式视觉需先展示预览并获明确确认。横屏触屏、设备性能与成品构建各自有独立验收条件。

## 一局如何展开

| 阶段 | 玩家看到什么 | 玩家要决定什么 | 系统如何反馈 |
| --- | --- | --- | --- |
| 开局准备 | 单局目标、起始资金档位和下一档条件 | 进入新种子的地图后，指挥员往哪里走、基地放在哪里 | 主基地启用后开放外围建造并开始调度敌袭 |
| 第一波前 | 主基地、矿点、资金和建造侧栏 | 第一笔钱先用来建立采集收入，还是先建防线 | 显示资金、建筑价格、占地、施工与生产结果 |
| 中盘 | 剩余资源、现有建筑耐久、已入场的敌人 | 是否开发新方位，哪里用固定设施守，哪里靠机动小队补位 | 展示资源耗尽、训练完成、外围损失和战场敌情 |
| 最后一波 | 已入场敌群、基地和防线状态 | 把资金投给修复、火力或防线 | 清完最后一波即获胜，基地被摧毁立即失败 |
| 结算和重开 | 击退数量、胜败原因、胜场进度 | 决定是否开下一局 | 同一局胜场只记录一次，新局按当前档位发放资金 |

## 系统职责

| 系统 | 玩家做的决定 | v0.7 玩法 | 首版需要验证 |
| --- | --- | --- | --- |
| 地图和镜头 | 读地形与方位，判断哪里值得投入 | 高位透视镜头可平移、旋转和缩放，焦点可回到指挥员或基地。种子改变资源布局与来向 | 默认视角能看清单位。移动镜头后仍能正确选址 |
| 基地 | 选择主基地位置，在采运、炮塔和基地耐久之间分配预算 | 主基地由玩家落位，有耐久和三条升级线 | 选址后可建范围和敌人目标正确。扣费和修复结果可读 |
| 资金 | 选择从哪里建立收入、什么时候投资采集站 | 采集员从有限矿点往返采运，卸货后入账 | 最低起始档能建立收入，耗尽、运回和入账可核对 |
| 建造 | 选择设施、位置和开工时机 | 建筑使用同一余额付费，在网格上选址。开工后显示施工进度，完工才生效 | 建筑位置改变采集范围、火力覆盖和通行。工期可读，受袭后能决定是否重建 |
| 守军和炮塔 | 决定何时付费训练、把哪支守军派往哪里 | 兵营完工后开放训练，守军和炮塔自动交战 | 调防能改变接敌结果，玩家能预留训练费用和时间 |
| 进攻和结算 | 建立防线，发现敌人后调防，根据战损改下一轮计划 | 六波敌人入场后可见，清完最后一波结算。胜场解锁下一档起始资金 | 玩家发现敌人后有调防机会，能说清失败原因 |

### 操作约定

- 地图和小地图用于查看局势。玩家在地图选址，从生产建筑下单，采集员自动行走、采集、返程和卸货。
- 局内 HUD 提供调防、建造、升级与暂停入口。建造在独立实时侧栏进行，显示库存、地块与价格，地图仍可操作。基地升级有独立入口并暂停局时。
- 当前键鼠入口为左键点选、滚轮缩放、`V` 建造、`B` 升级、`Esc` 暂停。键位是原型方案。触屏操作需要在对应阶段验证点选区域、缩放和面板遮挡。
- 影响生死或投入的操作应在下单前说明对象、成本和结果，在下单后给出成功或失败反馈。本局剩余时间、已入场的敌人和基地受损应在战场上读得出来。

## 探索、回归与局外成长

玩家在局外选择当前科技能进入的地图。地图按科技时代划分，每次进入都在野外随机出生。新档科技树为空，先从新手地图熟悉移动、探索和建造。玩家可以自己挑地方搭基础庇护所，保证指挥员存活。

| 阶段 | 玩家操作与规则 |
| --- | --- |
| 选图出发 | 查看可进入的科技时代与地图，选择目的地。进入后从野外随机出生点开始探索 |
| 探索与发展 | 探索获得资源，玩家决定把资源投入建造和防御，还是用于研究与升级 |
| 基础任务达成 | 开放主动回归。玩家可随时返回，也可继续探索、研究或挑战终极任务。前期任务主要是简单探索与生存，例如存活游戏内一天或一个月，完成通常只给少量资金 |
| 终极任务达成 | 自动回归并结算。基础任务达成后继续探索的选择，到此结束 |
| 成功回归与再出发 | 资金奖励取决于任务完成情况。科技按本局实际研究结果保留，和任务资金分别结算。回归后可以花资金强化自己，也可以直接选择下一张可进入的地图继续探索 |
| 指挥员死亡 | 本局结束并清空本次出发的内容。已采资源、建筑、任务进度、任务资金奖励和本局研究全部失去，包括已完成但尚未回归的科技。此前已保存的局外资金、科技和强化继续保留 |

局外科技树记录已研究的能力和进阶地图的进入条件。探索带来的资源支撑本局发展，研究成果让玩家打开新的地图选择。基础任务一完成，玩家就要决定现在回归结算，还是继续投入时间与资源争取更多成果。

[v0.10 探索战术扩展](探索战术扩展-v0.10.md)从木工、绳索和手工机械起步。荒野开放给新档，带回「野外测绘」后开放旧工坊，开闸回归后开放山口烽台。三张地图分别考验生存、绕行取材和守备。六波守城使用独立试玩入口和原有胜场档案。

## 待试玩验证的设计

以下是影响首版设计的问题和验证思路。拟采用的整版规则以送审稿列出的版本为准。

| 问题 | 候选规则 | 用什么判断 |
| --- | --- | --- |
| 经济投资是否值得 | 让早期采集站能在承受一次外围风险前回收成本，兵营或炮塔则直接提高一侧防守 | 固定同一个种子，比较先投资采集站与先补薄弱防线时的首笔支出、首波后库存和防线状态 |
| 中盘是否需要重新布防 | 对中盘某一波试做双向或错时进攻。两路敌情分别在入场后可见 | 同一个方向守到底的成本上升，玩家发现第二路敌人后仍能作一次调度或扩建决策 |
| 失败是否能复盘 | 清楚反馈外围建筑损失和主基地失守 | 首次试玩者能用自己的话说明为何失守，以及下一局会改哪一个决定 |

## 特殊任务候选 · 一次性续战

2026-11-10，用户认可把一次性续战作为特殊任务的候选规则。它借鉴《井口战役》中角色返回同一战场继续任务的结构。具体纳入版本和获取方式待定。

- **触发条件**。任务启用续战，本局还有一次机会，指挥员阵亡时己方据点仍在，且本局尚未判负。若阵亡与主基地失守同时发生，以主基地失守结算。
- **玩家选择**。符合条件时可选择消耗一次机会，在己方据点恢复指挥员并继续同一局，也可接受失败。再次阵亡时按任务的失败规则结算。
- **战场状态**。继续时只恢复指挥员。部队、建筑、物资、任务进度和敌军位置沿用阵亡时的状态。已发生的损失继续生效。
- **验证目标**。对照据点与采运线完整、据点还在但防线与采运线严重受损两种局面，观察复活后的首要决策是否不同。另核对复活机会只消耗一次，以及据点失守时直接结算。
