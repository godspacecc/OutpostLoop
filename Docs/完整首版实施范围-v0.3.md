## 整版目标与顺序

玩家从新档进入意外落地的求生处境，在镇中找水、食物和装备，选择现成房间落脚或轮换位置，活过三天后撤离。首次回归后认识空间，查看结果并主动开始下一趟。第二趟以修通桥头备用通道为目标，搜索维修零件、修复通道并撤离。空间不存任何物资，每趟空手开始。叙事沿用游戏总纲，第一趟数值、操作、物资数量、昼夜和结局沿用已确认 v0.5。

1. 第一批先复用现有大镇，完善从开始、搜取、装备和使用、落脚、保存续玩到结算与重试的整条路径。
2. 再接河谷镇实际可玩街区，检查建筑碰撞、搜点与路线；远景和未完成区域须可辨认。
3. 补首次回归和桥头行动，串联解锁、结果和持久进度。第二趟具体数值依实施前修订文档确认，不把备查细则自动视为本次确认。
4. 制作 Windows 本地可运行版，验证独立启动、退出重进与续档。用户本次确认包含本地构建交付，不包含公开发布。
