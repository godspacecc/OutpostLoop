# OutpostLoop 首版玩法设计

**版本 v0.5 · 2026-11-10 已确认**

这是首个完整可玩版的整版方案。当前 Unity 原型作为实现起点，方案包含沿用的原型规则和拟新增的玩法。全部内容经用户明确确认后，按同一版本组织开发和验收。

## 玩家体验

一局 12 分钟。玩家经营一座小型前哨，靠采集和扩建获得足够的收入与火力，撑过六波进攻。主要操作是选资源点、建造设施、下令训练驻军和调动机动小队。单位自动采运和开火，训练在玩家下单后自动推进。

比如西侧资源丰富。可以把采集站盖在离资源点近的位置，让机动小队留在基地附近。也可以先在火力薄弱的一侧放置路障，用炮塔射程覆盖敌人绕行的缺口。临时补炮时要靠现有守军撑过施工。到第四波，看到第二路敌人后，再决定让小队支援哪一边。

## 一局的流程

| 阶段 | 玩家操作与游戏反馈 |
| --- | --- |
| 开局准备 | 显示胜利条件、补给币余额及起始补给选项。确认开局后扣除所选补给币并入库，生成本局地图与波次 |
| 0 至 2 分钟 | 点资源派工。拿到首批库存后，选择先扩大产出或先补薄弱防线。首波敌人出现后，从场景或小地图观察并调防 |
| 2 至 6 分钟 | 开发第二片资源，观察设施产出与耐久。快速敌人考验火力覆盖，攻坚敌人考验外围设施的防守 |
| 6 至 11 分钟 | 第四波首次双向进攻。决定固定设施守哪边、机动小队支援哪边。第五波回到单向重压 |
| 11 至 12 分钟 | 最终波从两侧来。保住基地并清空全部来敌，等待时限结算 |
| 结算 | 显示胜负、存活时间、击退数量和结算原因。胜利发放补给币，选择再来一局时回到准备页并更换种子 |

## 地图、初始状态与资源

- 地面高位斜俯视，镜头默认围绕基地与周边防线，支持缩放到全图。移动边界半径 46 米。建造在基地周围的网格内落位。初版全图可见，小地图显示资源、友军和敌人。
- 每局 36 个有限资源点，24 个废料堆与 12 个能源点。单点分别含 18 废料和 8 能源。近基地六个点保证两种资源，避让开局建筑与单位的初始位置。换种子时刷新资源分布与进攻方向。
- 初始基地耐久 100，东、西各一座已完工炮塔，基地有一名自动采运工人与一支机动小队。默认库存为零，开局补给另计。
- 点场景或小地图中的资源点派工。工人初始移速 5 米每秒，每 0.6 秒采 1 单位，单趟容量 12。装满或采尽后自动返程卸货，改派时先卸现有货物。耗尽节点从地图移除，工人交付剩余货物后待命。
- 采集站与工人共享节点余量。两者同时开采时按工人、采集站顺序结算。已耗尽的节点不再给库存记账。基地库存支付升级和建造费用，两种资源一次性校验及扣除。

## 建造、升级与部队

### 网格选址

建造参考《红色警戒 2》的侧栏选择、鼠标占地预览和战场落位。OutpostLoop 采用先选址、再现场施工的顺序，施工进度在工地上显示。[Westwood《红色警戒 2》手册](https://manualzz.com/doc/24314810/westwood-studios-red-alert-2-user-manual)

1. 打开实时建造侧栏，选择建筑类型。任一种所需资源不足时，对应建筑在侧栏显示为灰色且不可点击，库存足够后自动恢复。鼠标移到战场时显示按格吸附的占地轮廓。绿色表示可放，红色显示阻挡或超范围等具体原因。路障可按 `R` 旋转 90 度。
2. 左键点击合法位置才扣费并开工。库存、上限和占地在点击时复查。右键或 `Esc` 退出选址，返回战场操作。选址期间地图点击用于放置，关闭侧栏、升级、暂停或结算时结束选址。
3. 送审地图参数为每格 2 米、距中央基地 24 米内可建，占地各格均须在范围内。核心基地占 3×3 格。现有建筑、工地、未耗尽资源和站在目标格里的单位占用位置。资源耗尽后释放其格子。地图预览同时标出采集站将绑定的节点。
4. 每局同时最多四座外围设施和四座炮塔，施工占用名额，开局两座炮塔计入上限。空闲可建格由玩家选择。已完工炮塔可在地图选中后免费即时迁移，目标同样经过落位校验，迁移保留开火冷却。

| 建造内容 | 占地 | 废料 / 能源 | 施工时间 | 完工后的作用 |
| --- | --- | --- | --- | --- |
| 采集站 | 2×2 | 8 / 0 | 5 秒 | 42 耐久，每 2.5 秒从绑定节点开采 1 单位直接入库，采尽后停产 |
| 兵营 | 2×2 | 14 / 3 | 8 秒 | 72 耐久。完工后开放「训练守军」，等待玩家下单 |
| 路障 | 2×1，可旋转 | 10 / 0 | 3 秒 | 150 耐久，挡住所占格的通行 |
| 炮塔 | 1×1 | 16 / 3 | 6 秒 | 90 耐久（送审值），从实际位置攻击射程内最近敌人 |

### 施工与完工

- 不同位置的施工可以并行。工地上方显示进度条，选中工地时侧栏同时显示剩余秒数。关闭侧栏后继续施工。暂停或打开基地升级时冻结进度，继续后恢复。完工收起施工条，建筑才开始工作。
- 工地从建筑最大耐久的一半开始。完工时补足其余一半耐久，已受伤害保留。工地或建筑被摧毁后释放占地及建造名额，已投入资源计为损失，可以重新付费建设。
- 采集站下单时绑定站点 12 米内最近的未耗尽节点，每个节点可绑定一座采集站。工人仍可采集该节点。没有符合条件的节点时禁止落位。节点在施工期间耗尽时，采集站按时完工并显示停产。

### 通行与攻击

- 工地、建筑和路障的占地格阻挡通行，落位、迁移或摧毁后更新路径。工人与机动小队走可通行的路线。工人从基地外围出发，在资源点和基地可到达的一侧采集或卸货。路线被堵时等待并显示原因，通路恢复后继续原指令。
- 敌人从生成方位沿可通行的最短路接近基地。途中有建筑或工地进入攻击范围时，优先攻击最近的目标。通往基地的路全被封住时，选择可接近的阻挡建筑攻击，打开缺口后继续进攻。敌人可以绕开路障，也可以攻击阻挡路线的炮塔。

### 训练守军与调防

- 在地图选中已完工的兵营，侧栏显示「训练守军」入口。施工费与训练费分别扣除。训练一支小队拟消耗 6 废料、2 能源，成功下单后立即扣费，训练耗时 12 秒。库存不足时提示缺少的资源。
- 每座兵营可训练并维持一支本侧驻军。训练中显示剩余秒数，已有训练订单或驻军时拒绝重复下单。暂停冻结训练，继续后恢复。兵营被毁时结束训练或移除已出场的驻军，已支付的训练费用计入损失。
- 训练完毕后，驻军在兵营附近的可通行格部署并自动交战。若出入口被堵，已训练的驻军等待空位。开局的机动小队另由玩家下达西、东、北或南的调防命令，自动行进并攻击射程内最近敌人，待命时也能保护基地附近。
- 炮塔初始射程 14 米，每 0.4 秒最多射击一次，每发 3 点伤害。机动小队和驻军采用 10.5 米射程、0.4 秒间隔与 3 点伤害。火力升级作用于炮塔。

基地升级在独立暂停面板进行。每条路线最多三级，各级统一花费 8/0、16/3、24/6 废料/能源。

| 路线 | 每升一级 |
| --- | --- |
| 采集与运输 | 携带上限加 4，移速加 1 米每秒。采集间隔为 0.6 秒除以 (1 + 0.4 × 等级) |
| 炮塔火力 | 炮塔射程加 3 米，每发伤害加 4 |
| 基地耐久 | 耐久上限加 50，修复 75 耐久，修复后最高为新上限 |

## 六波进攻与胜负

以下时间、敌人编成与来向供关卡规则使用。袭击在敌人实际入场后才通过场景和小地图可见。局内取消袭击预告，包括下一波方向、倒计时与次路提示。主要来向由种子生成，连续两波的主要来向不同。双向波的次路来自对侧，晚 5 秒抵达地图边缘。

| 波次 | 开始时间 | 普通 / 快速 / 攻坚 | 来向 |
| --- | --- | --- | --- |
| 1 | 2:00 | 10 / 0 / 0 | 单向 |
| 2 | 4:00 | 10 / 4 / 0 | 单向 |
| 3 | 6:00 | 12 / 4 / 2 | 单向 |
| 4 | 8:00 | 14 / 6 / 2 | 主路 9 / 4 / 1，次路 5 / 2 / 1 |
| 5 | 10:00 | 16 / 6 / 4 | 单向 |
| 6 | 11:00 | 18 / 8 / 4 | 主路 11 / 5 / 2，次路 7 / 3 / 2 |

| 敌人 | 耐久（第 n 波） | 移速（米每秒） | 近距离伤害（每秒） | 设计作用 |
| --- | --- | --- | --- | --- |
| 普通 | 16 + 3n | 1.5 + 0.1n | 2 | 形成基础进攻压力 |
| 快速 | 10 + 2n | 2.4 + 0.1n | 1 | 更早接触防线，考验常驻火力和发现敌人后的调防速度 |
| 攻坚 | 36 + 4n | 1.0 + 0.05n | 外围设施 5，基地 3 | 拉长交战并威胁外围经济 |

敌人进入目标 2.5 米范围后开始攻击。同屏最多 48 名存活敌人，超出的本波单位等到有名额再进场。基地耐久归零立即失败。12 分钟到时，基地存活且全部敌人已清空才获胜，存活或等待入场的敌人均视为未清空。终局后停止采运、建设、训练和战斗。

## 操作、信息与异常

| 界面 | 操作与时序 |
| --- | --- |
| 战场 HUD | 显示库存、工人载货、基地耐久、本局剩余时间和已发生的波次。左键派工，滚轮缩放，四向按钮调防 |
| 建造侧栏 | `V` 或右下角按钮打开，选建筑类型后在地图预览并落位。点击场上的工地或建筑查看施工、耐久、产出或训练状态。选址期间占用战场左键，建设、采运、训练和战斗保持实时 |
| 基地升级与暂停 | `B` 打开独立升级面板，战场上的 `Esc` 或暂停按钮暂停。选址时 `Esc` 先取消选址。打开暂停或升级时收起建造侧栏。退出后回战场继续，暂停时禁止建造、训练下单和调防 |
| 事件反馈 | 首次进入战场提示派工、建造、查看小地图和调防。敌人入场后显示在战场和小地图上。设施被摧毁时提示方位与类型，失败区分基地失守和时间耗尽。提示保留在可读区域 |
| 结算和补给 | 胜利一次发放 10 补给币，失败无奖励。每种补给每局可买一份，5 币换 8 废料或 3 能源。只在开始时扣币。保存失败时可以在结算页重试，避免重复奖励。单局状态随重开重置 |

## 相对现有原型的玩法变化

- 移除袭击预告。第四、六波从对侧分批进场，玩家根据已经出现的敌人判断要支援的防线。
- 预设地块与炮位改为建造范围内的网格选址。布局改变火力覆盖和通行，炮塔加入耐久与被攻击规则。
- 下单后生成工地并显示施工进度。炮塔、采集站完工后开始工作，外围工地可以受袭。
- 兵营完工后由玩家另行付费下单训练驻军。训练完成后守军在本侧自动交战。
- 敌群加入快速与攻坚两类，并用清晰的临时外观及攻击反馈区分。
- 机动小队开局待命时可以自动保护基地，接到命令后按原有四向调度执行。
- 增加首局操作引导、敌袭与建筑损失反馈，结算说明具体失败原因。

## 内容范围与验收

首版范围是一种地图规则、一种守城模式、两种资源、三种外围设施与炮塔的网格选址、两类友军部署方式、三种敌人和六波。兵种生产队列、长期城市存档、联机、更多地图和触屏发行均另立版本方案。此次送审范围为 Unity 编辑器键鼠试玩。正式视觉、设备交付和 Player Build 另按项目授权确认。

| 验收项 | 通过条件 |
| --- | --- |
| 操作完整 | 从 Boot 进入，按真实界面完成派工、建造、升级、调防、暂停、继续、结算和重开。两种资源、库存和建筑状态在关键步骤可核对 |
| 策略成立 | 同一种子及补给下，经济优先和防御优先两条路线均有可重复通关路径。记录首笔支出、首波与第三波后的库存、设施损失、布防和最终结果。换第二种子复验 |
| 敌情可读 | 入场前界面不显示袭击方向、倒计时或次路。敌人进入地图后可被发现，玩家仍有调防机会。第四、六波的两路敌人分别在各自入场后可见。敌人类型的差异影响布防，基地或设施受损后可辨识原因 |
| 选址有效 | 四种建筑可在合法位置放下。重叠、越界、占住单位或资源、超出数量上限及取消预览均不扣费。位置改变采集站绑定、火力覆盖和来敌路线。验证路障绕行、道路完全封闭时敌人攻击阻挡建筑，以及路障摧毁后路径恢复 |
| 施工可读 | 四种建筑都可在地图看到施工进度，选中地块时能核对剩余工期。验证并行施工、关闭侧栏、暂停恢复、工地受损及摧毁、采集点施工期间耗尽。炮塔和采集站完工后开始工作 |
| 训练可控 | 兵营完工后出现训练入口。主动下单时单独扣费，库存不足、未完工或重复下单时不扣费。真实 Play 中核对训练进度、暂停、兵营被毁以及训练完成后的自动驻防 |
| 状态一致 | 同时采集、资源耗尽、重复下单、库存不足、真正暂停、建造期间被摧毁、超额等待进场及终局都按本文结算。胜利奖励只发放一次 |
| 实际试玩 | 使用 Unity MCP 保留限定规则和真实入口验证，另记录至少一局人工操作从开局到结算。人工试玩需要能读出下一步、说明关键取舍并复述胜负原因 |

**本次确认对象为本文 v0.5 的全部玩法、操作、内容范围与验收。** 对具体规则有调整时，先修订整版方案再确认。确认后的版本与确认范围记入[执行总清单](执行总清单.md)。
