## 记录方式与后续顺序

1. 从 My Assets 加载并登记包名、发布者、版本和界面显示的下载／导入状态，注明搜索条件与读取范围。截图和记录放在本仓库的批次证据目录。
2. 优先核对角色、服装、骨骼与动画候选，再按当前制作需求核查环境、道具、音效。可用缓存辅助检查实际内容，但不能将缓存候选当作全部可选范围。
3. 每个候选分别记录来源已定位、内容已检查、适配已验证、正式采用已确认；这些状态不能互相替代。包名、文件路径与本机存在也不代替授权材料或效果验收。
4. 用户已有资源优先评估参考、复用或改造；缺项须在相关来源检查后才能判断。外部包不整套覆盖项目控制器、设置和依赖，其他项目美术仍按隔离规则处理。
5. 正式造型与动画采用仍需展示预览确认；本次来源范围纠正不代表 A／B 衣着、男性样貌或任何资源包已经获准正式采用。
