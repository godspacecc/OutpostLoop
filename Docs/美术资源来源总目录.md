## 导入后的统一目录

2026-11-20 · 用户确认后续导入 Unity 的第三方资源包统一归入 `Client/Assets/ThirdParty/<发布商>/<资源包>/`，可在当前项目的 **Project → Assets → ThirdParty** 浏览。

1. 导入整包或选择其中的文件时，以发布商和包名作为目录，保留包内场景、预制体、贴图等结构。Survival Clean 的目标目录为 `Client/Assets/ThirdParty/Layer Lab/GUI Pro-SurvivalClean/`。
2. Package Manager 若先导入到包作者的默认目录，在 Unity 的 Project 窗口移动整个包目录。导入工具可用 AssetDatabase 执行同样的移动。保留随资产一同移动的 `.meta` 和 GUID。
3. 导入批次结束前，检查包目录位于 `ThirdParty/`，打开代表性的预制体或演示场景核对引用，并记录发布商、包名、版本、实际导入范围及最终路径。
4. 项目自制或维护的派生资产放在 `Client/Assets/Game/` 的对应位置，并保留来源记录。Unity 自己管理的 UPM 依赖照常通过 `Client/Packages/` 管理。已有资产和导入脚本在各自批次安排迁移。
