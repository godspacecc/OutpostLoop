# OutpostLoop v0.8 战争迷雾

**2026-11-10 · 已确认**

开局只看得到指挥员附近。玩家走到矿点附近才能发现它，找到合适的位置后再放主基地。基地落位后，建筑和单位一起提供视野。敌袭实际进入己方视野时，玩家才知道哪里需要调防。建造、生产和胜负采用 [v0.7 正式玩法](首版玩法设计.md)。

## 地图和视野

| 地面状态 | 战场与小地图显示 |
| --- | --- |
| 未探索 | 黑色遮罩，隐藏该处的地形细节、矿点和敌人 |
| 已探索，当前看不到 | 灰色遮罩。地形和已发现矿点保留上次看到的信息。敌人标记消失 |
| 当前可见 | 明亮显示实时地形、矿点余量和敌人。己方视野随移动、出场与摧毁更新 |

- 指挥员视野 16 米，主基地 20 米，采集员 12 米，守军 14 米，完工采集站和兵营 10 米。炮塔至少提供 16 米视野，火力升级让视野跟上实际射程。路障和工地显示在地图上，视野由附近的己方单位及完工建筑提供。
- 首版按地面半径合并己方视野。矿点或建筑不阻断视线。镜头平移、旋转、缩放和查看小地图只改变观察角度。每局按新种子重新记录探索范围。
- 开局可右键让指挥员走进黑区。采集员沿采运路线自动揭开沿途视野，守军沿调防路线自动揭开沿途视野。

## 选址、采矿和敌情

- 主基地、外围建筑及炮塔迁移的所有占地格都须在当前己方视野内，再校验建造范围和实际占地。预览先判断视野，视野不足时显示「该位置不在视野内」。开工后即使后来失去视野，已下单的工地继续推进。
- 采集站在已发现的有效矿点中绑定最近目标。矿点在灰区时只展示上次观测到的状态。采集员可以自行前往已发现的绑定矿点，接近后更新余量。主基地选址须保证基地启用后，其视野内至少有一块可建采集站的地，且能接入已发现的矿点。若附近还没找到矿点，可以在敌袭开始前继续侦察。
- 敌人只有进入己方视野后才出现模型、小地图标记及首次发现提示。HUD 显示已发现的波次，离开视野的敌人从战场与小地图消失。第四、六波的第二路独立显示，玩家看到哪一路就响应哪一路。
- 己方防御单位在目标进入己方视野且处于自身射程时交战。己方建筑受损或被摧毁可显示防守反馈，敌军具体位置按视野决定。

## 验收

| 验收项 | 通过条件 |
| --- | --- |
| 开局探索 | 从 Boot 进入，只看到指挥员附近。右键走入黑区，沿途逐步点亮。回走后，远处变灰且保留已探索地形。只移动镜头时可见范围保持在己方视野内 |
| 选址与经济 | 黑区和灰区的落位预览均拒绝且不扣费。侦察后能建立主基地及采集站，采集员正常卸货。矿点离开视野后保留最后观测信息，重新进入视野时刷新 |
| 敌袭与视野来源 | 敌人从黑区入场时无模型、标记或预告。进入视野才显示，离开后隐藏。单位调防或建筑被摧毁后，两张地图同步更新，第二路来敌独立显现 |
| 整局与重开 | 仍能从最低资金档找到矿点、建立收入并清完六波。重开恢复未探索状态。用 Unity MCP 核对两种种子的选址与防守，并保留战场和小地图实景 |
