## 布局与来源

使用已导入的用户 POLYGON City／Generic 派生目录；复用现有 `shelf`、`desk`、`wall`、`floor` 和原有箱件。没有导入外部场景、脚本或其他项目美术。缺少自有美术目录的检出会显示同占地占位物，避免无形家具或开局空引用。

- 保留西门和原有床、储物柜的位置。销售区 7 组双面货架，后仓 4 组货架，收银台 1 组（三段柜台模型），后仓隔断 2 段，加床柜共 16 个实体占地。
- 中央主通道的地面标示带宽 3.8 米，后仓隔断开口 3.2 米。后仓东侧两排货架收窄至 1.2 米，保留靠墙侧道；通路按角色 0.34 米半径验证。
- 原杂货店搜点移到收银台前的可站立位置；箱模型置于柜台上。逻辑交互点与箱模型位置分别记录，避免玩家需要站入柜台。容器索引、物资和搜点数量不变。
- 领域碰撞和模型读取同一份固定陈设布局。每组货架／隔断独立登记遮挡；遮住玩家时整组隐藏，离开视线恢复，逻辑碰撞保留。
- 新版行动移动采用不超过 0.12 米的分步判定，视线采用线段与实体矩形的精确判定，防止跨过薄隔墙。

## 存档与边界

新开局使用地图布局版本 2；旧小街区版本 0、原整图空室内版本 1 均按原地图恢复。版本 1 玩家即使停在未来货架的占地内，继续游戏仍保持原位置与空室内。旧档同种子重试保留原版本，结束后重新出发进入新版。存档文件名与保存格式保持原有约定。

本批不增加容器、任务、敌人、物资总量或时长。两处基地和六处重点室内仍沿用整图方案。布局升级只移动新版杂货店原搜点，原床柜互动继续使用原有距离与操作。

## 验证记录

最终 5 项全部通过：`shop-rules-final3.json`（3 项）、`shop-full-final2.json`（1 项）、`shop-boot-final2.json`（1 项）；汇总见同目录 `final-evidence.json`。按代码审查与测试证据审查方法核对，当前编辑器室内交付无阻断问题；正常局时体验与设备性能不在这些通过项的证明范围内。

3 项室内规则覆盖：所有销售货架双侧、后仓侧道及床柜交互位置的独立网格连通；大步长不穿家具与隔墙、隔墙挡视线而开口可见、搜索和读档不重复增加实体；可见模型不越出共享碰撞占地且逐组登记遮挡。

`BootRiverValleyFullTownHasSixInteriorsAndKeepsLegacySaves` 从 Boot 点击进入新局。在入口处受控定位后，使用领域移动逐步走完收银、后仓、床、储物柜与返回西门；检查搜索、睡眠恢复、存入取出、实际出门关门及货架遮挡恢复。兼验六入口、三桥、原有物资／敌人数、新版续玩、版本 1 原位恢复、版本 0 恢复与旧局结束后重新进入版本 2。

`BootSurvivalOpensTownWithIndependentSurvivalClock` 回归真实入口、生存时钟、输入、暂停与续玩。

初次网格检查发现后仓东侧侧道余量不足，收窄两排货架后通过。第一次 Boot 步行测试在离门 1.7 米处尝试关门，超过原有 1.65 米交互距离；将验收步行终点调整至门外约 1.3 米，未改房门交互规则。原始失败和复验结果一并归档。MCP 汇总 Duration 出现异常的大跨度值，耗时只参考逐项 Duration，不将汇总字段作为性能证据。

证据限定为编辑器真实入口、自动输入／领域步行、受控镜头遮挡与截图检查；为隔离家具验证，在确认敌人可造成伤害后停用了该次测试中的敌人。未据此宣称真人连续三天试玩、战斗平衡或目标设备性能通过。独立检查图暂时省略屋顶、使用尺度胶囊，实际 Game View 截图保留游戏镜头与现有玩家表现。没有执行 Player Build 或发布。

下一项建议沿用同一方式完善住宅生活区，再处理诊所和仓库；本批未启动其他建筑的室内制作。
