# OutpostLoop 故事大纲 v0.3 · 界口战争

2026-11-10 · 待审阅的故事总纲，已修订出发与回归设定。[《门外有人》](故事大纲-v0.2.md)保留为早期方案，[《断线》](三部穿越小说的玩法与叙事参考.md#战争故事候选--断线)属于本大纲下的一次战地行动。

## 战争为什么开始

玩家来自一个和平的世界。多年前，两个世界的商人和测绘员在少数地点建立了往来，河谷人把战区一侧的通行点叫作界口。早年往来每次只能通过少量人员和物资。粮食、木材和伤员仍要靠当地道路运输。谁占住界口附近的道路和仓库，谁就能控制这片战区的往来。

河谷各镇过去和北军所属的领地一起维护这些通路。北方当局担心外来军队借河谷进入自己的腹地，要求河谷交出界口及沿线驿站，由北军统一驻防。河谷各镇只肯接受共同查验。北军便抢占大道和粮仓，把原先来往的渡口改作军用关卡，要用封锁逼河谷交出其余入口。河谷守军一边抵抗，一边请原来与他们来往的另一边派人增援。

## 玩家是谁

玩家是第一批增援人员中的一名外勤军官，任务是帮河谷守军恢复补给线。每次出发都在故乡的一间派遣站开始。到了前线，他就地采集、建设和防守，回归后在同一个派遣站交回地图、研究和战况。

派遣站可以把外勤送入战区，也可以直接把还活着的外勤从所在位置接回来。这条联络只供派出的人员往返。当地守军、伤员和粮车仍走战区里的道路。北军能夺走通路、围攻玩家，却碰不到玩家故乡的派遣站。前线任务何时达标、带回哪些成果，沿用现有的主动回归、自动回归和失败结算条件。

同批穿越者分散在不同战段，有人负责救援，有人负责探路，也有人奉命守界口。他们有自己的任务和遭遇，玩家只是这场战争里能独立指挥一段行动的人。河谷守军也有自己的指挥系统，会用外勤送回的情报决定下一步。

## 战争如何变化

**前段，河谷在封锁下争取活下来。** 北军控制大道，有条件把兵员和粮车集中到正面。河谷的优势是熟悉山地，还有一些北军以为已经废弃的道路和设施。外勤们一次次把路线和工法带回来，河谷才开始恢复不同据点之间的联络。《断线》就在这一阶段，目标是从封锁线后接出一支被困的守备队。

**中段，争夺从大道扩展到山里的补给线。** 当河谷能绕开大道运粮，北军开始分兵夺取山路和转运点。外勤可以结束这一趟、回故乡休整。河谷守军如果放掉一条路，就可能有整座镇子收不到粮。派遣方建议把有限人手集中到最容易守的通路，河谷守军则需要几条路同时通行，免得再被一处关卡卡住。两边仍并肩作战，却要决定下一批人和物资往哪送。

**后段，河谷必须有能力自己守路。** 外援人数有限，北军总能选下一处薄弱点再打。河谷守军把各支外勤带回的路线、工事和修造方法交给各镇，让他们能分别守住就近路段。外勤们在关键方向拖住北军，各镇趁机接通替代通路，让伤员、补给和守军可以分路走。北军最终失去用一条封锁线控制河谷的能力。这个转折由多处战地行动累积起来，玩家参与其中。

## 战争的结局

北方当局接受停火，撤出抢占的粮仓和部分通路。河谷各镇同意在界口共同查验军用物资，人员往来由两边协商。外勤队撤回，沿线守备交给河谷各镇。停火后的第一份军报记下，一支河谷守备队已经沿战时抢通的山路换防，途中用的是外勤带回、当地工兵照着造出来的备件。

这场战争以河谷能继续维持自己的补给和通行为结局。界口仍然存在，两边怎样相处也仍然需要人去决定。

## 与重复游玩的关系

战争大纲为任务、阵营和美术提供共同背景。玩家每局从安全的派遣站出发，进入一次独立的战地行动，再按该局结果回归和结算。现有荒野、旧工坊、山口烽台属于战争前段，新的种子代表同一类行动在不同落点的展开。停火收束这场战争的故事，派遣站依然可以组织下一次行动。

现阶段送审范围是战争起因、玩家身份、双方动机、战争转折和结局。首版现有任务继续以[已确认的探索玩法](探索战术扩展-v0.10.md)为准。中后段是剧情背景和未来选材，具体可玩内容另行确认。
