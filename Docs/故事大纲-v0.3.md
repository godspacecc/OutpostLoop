# OutpostLoop 故事大纲 v0.3 · 界口战争

2026-11-10 · 待审阅的故事总纲。[《门外有人》](故事大纲-v0.2.md)保留为早期方案，[《断线》](三部穿越小说的玩法与叙事参考.md#战争故事候选--断线)属于本大纲下的一次战地行动。

## 战争为什么开始

两片本来互不相通的土地，偶尔会在少数地点接上。两边把这些地方叫作界口。最早通过界口的是商人和测绘员。界口一次只能通过少量人员和物资。穿过以后，粮食、木材和伤员仍要沿当地道路运输。谁占住界口附近的道路和仓库，谁就能决定另一边的人进来以后能走多远。

河谷各镇过去和北军所属的领地一起维护这些通路。北方当局担心外来军队借河谷进入自己的腹地，要求河谷交出界口及沿线驿站，由北军统一驻防。河谷各镇只肯接受共同查验。北军便抢占大道和粮仓，把原先来往的渡口改作军用关卡，要用封锁逼河谷交出其余入口。河谷守军一边抵抗，一边请原来与他们来往的另一边派人增援。

## 玩家是谁

玩家是第一批增援人员中的一名外勤军官。对岸的派遣方给他的命令是保住己方人员能够往返的路线，河谷守军需要他帮忙打通本地补给线。开战初期，两件事指向同一个目标。玩家每次从对岸的派遣地进入战区，到了前线就地采集、建设和防守，回归后交回地图、研究和战况。

同批穿越者分散在不同战段，有人负责救援，有人负责探路，也有人奉命守界口。他们有自己的任务和遭遇，玩家只是这场战争里能独立指挥一段行动的人。河谷守军也有自己的指挥系统，会用外勤送回的情报决定下一步。

## 战争如何变化

**前段，河谷在封锁下争取活下来。** 北军控制大道，有条件把兵员和粮车集中到正面。河谷的优势是熟悉山地，还有一些北军以为已经废弃的道路和设施。外勤们一次次把路线和工法带回来，河谷才开始恢复不同据点之间的联络。《断线》就在这一阶段，目标是从封锁线后接出一支被困的守备队。

**中段，争夺从道路转向界口。** 当河谷能绕开大道补给，北军发现光靠封锁逼不出结果，开始攻打仍能通行的界口。玩家的派遣方也改了命令，准备集中力量保住一处易守的出口，其余路段随时可能放弃。对外勤而言，那是可以撤走的路线。对河谷的人而言，那些是几座镇子仅剩的补给和撤离通道。双方仍在并肩作战，却要面对同一个问题：哪些地方值得继续守，谁来承担守不住的代价？

**后段，河谷必须有能力自己守路。** 外援人数有限，北军总能选下一处薄弱点再打。河谷守军把各支外勤带回的路线、工事和修造方法交给各镇，让他们能分别守住就近路段。外勤们在关键方向拖住北军，各镇趁机接通替代通路，让伤员、补给和守军可以分路走。北军最终失去用一条封锁线控制河谷的能力。这个转折由多处战地行动累积起来，玩家参与其中。

## 战争的结局

北方当局接受停火，撤出抢占的粮仓和部分通路。河谷各镇同意在界口共同查验军用物资，人员往来由两边协商。外勤队撤回，沿线守备交给河谷各镇。停火后的第一份军报记下，一支河谷守备队已经沿战时抢通的山路换防，途中用的是外勤带回、当地工兵照着造出来的备件。

这场战争以河谷能继续维持自己的补给和通行为结局。界口仍然存在，两边怎样相处也仍然需要人去决定。

## 与重复游玩的关系

战争大纲为任务、阵营和美术提供共同背景。每局是战争中的一次行动，有独立战报和成败。现有荒野、旧工坊、山口烽台属于前段，新的种子代表同一类战地行动在不同落点的展开。停火是故事总纲的收束，任务重玩仍按各自发生时的战局呈现。
