# OutpostLoop 探索故事 v0.1 · 山口重燃

2026-11-10 · 待确认故事稿。依据[已确认的 v0.10 探索玩法](探索战术扩展-v0.10.md)编写。本稿为剧情和美术提供设定，涉及的新名字、人物关系及对白均为候选。

## 开场

洪水冲毁了河谷大桥。沿河的几座村子从此只能走山路，可山上的烽台早已熄灭，旧工坊也关了门。一伙自称「守路人」的旧巡路队守住仅存的运料道，谁要过路，就得留下半车货。

河谷的补给越来越少。村里派你去找一条旧路。你的任务是找到能走的路，把所见带回来。出发前，守仓人把一册空白的测绘簿塞进你包里，只交代一句。

> “能回来就先回来。你走过的路，我们才敢让下一队走。”

## 三次出发

### 荒野 · 找到旧路

你从冲垮的路段外绕进荒野。以前的运料道已被草和落石遮住，只有几截矮石墙和磨平的石桩还露在外面。你先找木料、石头和纤维，搭个能撑过第一轮搜索的落脚处。守路人的巡队也在找通往山里的小路，发现新搭的棚子，就会先拆掉它。

你可以活着回去，先把完成的研究交给村里。带回野外测绘后，村里能沿图找出通往旧工坊的支路。如果继续走到遗迹勘察，还能确认石桩之间原本有一条岔道，为这次出发带回更完整的路线记录。

### 旧工坊 · 打开闸门

旧工坊以前给各村修手推车、换绳索，也替山口修运料设备。撤走时，工人放下木闸，把制图台和山路图锁在院内。洪水以后没人回来，绞盘缺了木轴，旧绳也断在横梁上。

木料棚里有可用的轴，另一边的棚里还有粗绳。你找齐两件材料，修好绞盘，把闸门拉起来。守路人发现有人走这条支路，便试图把闯进来的测绘员赶出去，并拆掉新搭的设施。只要活着把工坊已经开闸的消息带回去，村里就能按旧路标找到上山的入口。若还能走进院里临摹制图台上的图纸，下一队便能带上更完整的工坊记录。

### 山口烽台 · 让对面看见

从旧工坊上山有两条路，都通向一座低矮的石台。河谷约定过，烽火告诉对面的村子这里有人，旗号才告诉他们这条路可以走。你带着第一段路线记录到了山口，找到留下来的柴料，重新点火。

烟一起来，守路人就知道有人在恢复旧路。山口一旦重新通行，他们就守不住收费的运料道。他们从两条山路循烟赶来，想赶走你、拆掉挡路的工事。你守着火，击退赶来的队伍。若还有余力上高台升旗，对面就能看清完整的通路信号。这三次出发的故事停在旗子展开的那一刻。

## 敌人是谁

「守路人」曾经替村子引路和搬运。大桥断后，队伍靠控制通道和截取物资维持补给。现在仍有人巡路，也有人专门拆工事。他们和玩家用同一时代的木、石、绳、布与少量手工金属件。旧工坊里熟练使用绞盘的是指挥员，守路人的造型也应看得出他们原先干的是搬运和巡路。

| 角色 | 故事职责 | 美术依据 |
| --- | --- | --- |
| 指挥员 | 村里派出的测绘员，带着路线和研究成果回去 | 方形测绘包、折尺或卷图、暖赭斗篷。高位镜头优先读肩背 |
| 普通敌人 | 巡路者，成队查找新路和新搭的庇护所 | 直立剪影、木棍、旧绑腿，褪色砖红肩布可作为共用标志 |
| 快速敌人 | 在两条路之间奔走通报的跑手 | 前倾轻装、露出小腿、短窄肩布，以步态和轮廓区分 |
| 攻坚敌人 | 以前清路和搬货的重工，负责拆掉挡路设施 | 宽肩、粗木槌、厚布护肩，动作重心低。木槌呼应攻击防御建筑的职责 |

## 供美术评审的场景证据

- **荒野**用半埋的路桩、被冲断的石墙和没入草里的旧路，讲清原先有人通行、如今需要重新测绘。临时庇护所用当地能找到的木杆、草和绳搭成。
- **旧工坊**把木轴的空位、断绳、压在地上的闸板放进同一视线。升闸后能看见开通的路和里侧制图台。两个棚子分别通过原木截面和成圈粗绳识别。
- **山口**让两条进场山路通向同一个石台。烽火负责远距离可见，旗杆放在更高的位置。火和烟的表达从俯视角就能看懂，同时服从现有迷雾显隐。

评审顺序为故事与阵营设定、旧工坊实景样片、其他地图和单位。旧工坊概念图可用于讨论材质与比例。正式采用以故事审阅后的 Unity 实景预览为准。独立守城试玩的敌人背景另立故事范围。
