## 来源与适配

- 主要资源入口仍为用户的 Package Manager → My Assets，本批使用已定位下载缓存，不将缓存当作全部资源。
- 人形、手枪网格来自已选 POLYGON Prototype。包内没有撬棍，补作无碰撞的简易撬棍表现。
- 单手挥击复用 Human Melee Animations FREE 的男性 `Attack1H01_R`；原地播放并按既有 0.8 秒攻击间隔适配。
- 瞄准姿态复用 JU TPS 2 的 `Rifle Idle Aiming` Humanoid 动作，移除供应者动画事件；不导入其控制器或脚本。双臂用解析双骨约束适配手枪握点。
- JU TPS 的 `ReloadPistol` 是武器零件动画，未冒充人物动作使用。人物装填与射击后坐为程序骨骼覆盖，装填进度读取现有 actionTime。
- 上身 AvatarMask 保留腿部移动层。暂停、帮助和区域图期间随既有状态冻结，不推动局时。
