# 桥头行动实施方案 v0.4

2026-11-13 · **待确认的具体规则。** 依据已确认的完整首版 v0.3「修通桥头备用通道」目标细化，不引用已删除故事稿。本稿数值尚未作为实施授权。

玩家在首次活满三天并成功撤离后，从空间看到下一趟任务。再次出发仍为空手，落在河谷镇主镇西侧公路桥附近的东岸后街。玩家选择沿主街直接找零件，或经岸边支路绕开感染者，修好桥东引道的闸门，再亲自穿过桥梁，到西岸撤离。行动结果显示通道是否已经恢复。

| 项目 | 建议规则 |
| --- | --- |
| 进入条件 | 第一趟达标并撤离；提前撤离、阵亡及超时只能重试第一趟。成功标记跨退出保留 |
| 时间 | 20 分钟上限，本地时间从 16:00 开始；沿用每分钟一个游戏小时的昼夜。最后 5 分钟预告，无额外两分钟窗口 |
| 地图 | 取现有河谷镇主镇西侧公路桥附近，单独接入约 220×180 米行动区域。保留真实河道与桥梁关系；两条陆路在桥东引道汇合。其余区域仍为未开放外景 |
| 内容数量 | 两条路线各 3 处搜点，共 6 处；1 个现成房间、1 个可修闸门、1 个完成撤离点，另保留起点提前撤离入口 |
| 感染者 | 普通 4 个、快速 1 个，沿用现有巡逻、视线、声响调查、追击与破门规则 |
| 生存与背包 | 初始身体状态及饮食、受伤、疲劳、睡眠、照明、六格背包、装备位和操作沿用第一趟；空手落地 |
| 搜点物资 | 共 2 份水、2 份食品、2 份绷带、1 根撬棍、1 支自带电池的手电、2 份维修零件。每条路线保证 1 份水及 1 份零件，其余按种子重排 |
| 落脚房间 | 东岸现成房间可设基地，使用床铺和储物柜；沿用入口加固、维修规则，未投放的材料不能凭空取得 |
| 修复闸门 | 桥东引道闸门侧按 E；需要 1 份维修零件，连续操作 10 秒。完成时扣料开门，施工产生声响；移动、受击或 Esc 取消，不扣料。同一闸门不能重复收费 |
| 完成 | 修好闸门并亲自穿桥，到西岸撤离点按 E。结算记录通道恢复及用时，回到空间；物品不继承 |
| 未完成 | 阵亡、超时或从起点提前撤离均未完成。保留第一趟完成标记，可空手重试第二趟，重新生成种子 |
| 续玩 | 行动中保存并返回菜单，恢复相同时间、道具、门、敌人及闸门状态。空间与第二趟结果跨退出保留。保存失败不丢弃当前会话 |
| 版本结束 | 第二趟成功后显示本版行动完成，允许重试已开放行动或退出；不虚构第三趟目的地 |

## 验收

1. 全新存档达标回归后出现任务简报；提前撤离和失败均不提前解锁。
2. 同一种子分别走主街与岸边支路，用第二个种子复验；记录取水、零件、敌人调查、修复和撤离。
3. 缺件、施工中断、重复提交、受击、修复完成和窗口关闭边界有明确反馈；物品消耗只发生一次。
4. 修复前不能穿闸，修复后真实过桥；河道不可穿行。可玩边界、搜点、床铺、闸门和撤离点可辨认。
5. 分别在修复前后保存退出重进，检查局时、物品、敌人、门和结果；空间不能取出任何装备或物资。
6. Unity 限定测试保留全部通过项，并核对实际入口与画面；正常键鼠整局体验和安装版验收分别记录。
