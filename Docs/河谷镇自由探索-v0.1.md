# 河谷镇自由探索 v0.1

2026-11-19 · 用户要求撤下「大镇与镇郊 · 探索试玩」独立入口，把内容合进河谷镇。用户明确要求由玩家自由探索发现，并在查看修订方案后回复「可以」。

## 游玩方式

- 从「开始游戏」或「继续游戏」进入河谷镇。玩家走进社区诊所，在近距离可以按 E 或点击交谈，听幸存者提起药品曾转运至医院。
- 自由搜索仓库时，装卸架里可以读到药品转运记录。搜索和拿取物品沿用现有操作。
- 区域医院入口层的急救包一直可以正常搜索、拾取和使用。可以直接去医院，也可以只听对话、只读记录或完全跳过。
- 两处发现可重复查看。没有任务状态、新地图标记、结算奖励或存档字段。三天生存、撤离、物资数量和其他试玩入口沿用现行规则，旧街区续玩兼容路径继续可用。

## 验收

从 Boot 查看其他试玩，核对旧大镇入口移除及其余入口保留。进入河谷镇后核对诊所对话距离、仓库搜索完成后的记录、直接拾取医院急救包，验证地图与生存目标和旧续玩流程。
