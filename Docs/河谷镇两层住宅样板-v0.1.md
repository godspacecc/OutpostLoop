# 河谷镇两层住宅样板 v0.1

2026-11-20，用户回复「可以 按你推荐来」，确认在现有可进入住宅制作一栋两层可玩样板。

- 从 Boot 进入河谷镇，进住宅后沿楼梯用 WASD 连续上下楼。可停在中段或原路折返。保留一楼原门、床和储物柜，二楼为一间可探索房间。
- 楼层限制搜取、掉落物交互和攻击。首批感染者留在地面，楼梯追击单独验证。楼层和楼梯位置可以续玩，已有旧地图存档按原布局恢复。
- 镜头随角色高度，上层楼板、屋顶和墙面按视线和当前楼层切除。先核对项目已有 Polygon Generic 楼梯资源，并在可玩样板展示适配结果。
- 验收走通地面到二楼再返回、楼梯中段停下和折返、二楼边缘阻挡、隔层搜取和攻击、楼层遮挡及二楼和楼梯续玩。

## 试玩入口

从 Boot 开始新的河谷镇行动，到住宅区的可进入住宅。开门后沿靠墙的木楼梯上行，二楼是可走动的空房间。新版行动布局为 3，续玩继续使用存档中的地图布局。版本 0、1、2 分别按原布局恢复。

楼梯沿用 Polygon Generic 的 `SM_Bld_Base_Stairs_01.fbx`，两段直跑连接 3 米层高。现有 City 派生墙、地板与屋顶用于同一住宅。模型适配和照片属于编辑器试玩样板。
