# OutpostLoop v0.11 跨界战役方案

2026-11-10 · 整版送审稿。目标是交付一段可以打完、也可以重复游玩的单人战役。下列阵营、世界、规则和数值均为本版提案。

玩家是一名联防署登记的穿越指挥员。他亲自进入真实战场，在敌军压力下选址、采运、建立防线并完成军事任务。每次出击都有独立胜负。前几场取得的战果会改变最后一场的补给与来敌。整场战役以切断敌军的重装备增援、让当地守军接管战线结束。

## 一、谁在打这场仗

**联防署**由数个已能互相往来的世界共同组建。各地守军提出军事请求，联防署负责协调派人、核定装备额度和结算战果。玩家来自联防署所在的成员世界，是众多登记指挥员之一。每次出发都在联防署的同一间派遣室进行，成功回归也回到这间房。游戏用出发页和结算页表现这间房里的操作，玩家直接选任务和配装。

**远征军**先占领灰原的一处旧货场，再把石港的重装备送进灰原，准备控制当地工坊和物资运输，维持自己的军队。灰原守军能击退一次进攻，但远征军能一批批补充火力。守军提出的请求是保住工坊，并找出重装备究竟从哪里来。

双方用的跨界方式不同。联防署的装置能把人和少量装备投送到已确认的落点，并把登记人员从任务区域接回。远征军在石港和灰原之间建立了固定的双端转运设备，能连续输送远超个人额度的装备，但设备只能在固定位置运行。**前线每打退一支队伍，远征军就能补一支。只有夺下石港那一端并切断转运，灰原守军才能留住自己赢下的战果。**

## 二、完整剧情

| 行动 | 开端、转折和结果 |
| --- | --- |
| **1. 工坊守备** | 玩家到灰原接替一段防线。远征军直接攻打仍在给守军供货的工坊。玩家守住交接期后，灰原守军接管。战后回执显示，对面损失的装备很快又从旧货场补齐。 |
| **2. 伏击车队** | 联防署根据守军提供的既有情报，派玩家在两条运输路线之间选址。远征军按原计划派车，车队护卫进入火力范围后被截住。玩家带回调度器，确认重装备来自石港，并查明可以投送人员的落点。 |
| **3. 石港立足** | 玩家到石港修复废弃装卸平台，守到当地抵抗部队接管。修复成功会给最后一战留下补给，但调度器已能提供一条独立进场路线，因此玩家也可以直接接终局任务。 |
| **4. 切断转运** | 玩家进入转运设施所在的战区，夺取控制点，接上当地工兵预备的断接装置，并顶住远征军的反扑。装置运行完毕后，重装备无法再由石港送入灰原。当地守军接管设施，联防署召回玩家。最后的战报交代灰原的重装备增援已停止、工坊交接完成。 |

玩家在开局能听到灰原守备官提出请求，终局由石港工兵确认断接，结局由两地守军分别回报。战役给一场有起因和结局的战争。单局重玩则允许用不同装备和种子重新打同类行动。

## 三、两层系统如何交接

| 系统 | 决定什么 |
| --- | --- |
| **派遣与结算** | 出发时选任务和配装，显示落点范围、战果、失败条件及回归方式。确定后锁定当局配置。结算分别登记本局结果、研究记录和战役进度。 |
| **任务世界** | 决定地形、材料、移动、视野和敌军行为。可建设的位置和能否维持采运由玩家在战场上判断。 |
| **战役状态** | 记录四项行动的完成标记。伏击完成会同时开放石港立足和切断转运。石港立足成功后，下一次进入终局行动时多得到一批补给。 |

联防署的回程装置在出发时锁定人员和本次行动区域。任务达标后，玩家仍活着即可在区域内确认回归，回归成功后回到派遣室。任务失败时，存活的指挥员可由系统执行撤回，失败成果按结算规则处理。指挥员阵亡会结束该次行动，继续游玩从失败结算重开。

## 四、玩家每局怎么打

1. **出发。** 在行动页查看敌军类型、达标条件、可带回成果和对后续战役的影响。选择一套随身配装，确认后投送至合法落点。
2. **选址和建设。** 指挥员先确认视野内的资源、遮挡和来敌通路，再部署主据点。手采能在开局快速取得物资，采运棚完工后从绑定资源点持续采运。玩家把同一份物资花在采运、训练、火力和防御上。
3. **执行任务。** 守军与机枪座自动接敌。玩家调动小队、修复设施、拉起第二道防线或争夺任务点。敌军从可通行方向进入，靠近后可观察到兵种和路线。若侧翼暴露，需要临时调兵或调整工事。
4. **回归或加码。** 基础目标达成后，可以主动回归。每场还有一个可选目标，玩家可以多留一段时间争取研究线索或首通奖金。切断转运完成后自动回归，战役结束。
5. **结算。** 结算页显示结束原因、本局任务完成情况、可带回的研究、局外报酬及下一步开放内容。玩家可接下一场、重玩已开放行动，或回到出发页。

### 入场配置与两种世界条件

指挥员基础生命 100。出发时三选一。**标准**带 65 物资，**采运**带 50 物资及一个可立即建造的便携采运棚名额，**守备**带 50 物资和两名守军。采运棚仍需合法选址并完成施工，守军仍受本局人口上限。配装每局重新发放，局外资金用于一次性训练。

| 世界 | 会改变什么打法 |
| --- | --- |
| **灰原** | 开阔地可观察远处敌人，田埂和墙体形成通路与遮挡。资源多在外围，采得快就要把防线铺得更远。 |
| **石港** | 敌我地面单位都只能沿堤岸、平台和连接路移动。低洼区域每 90 秒涨水一次，持续 25 秒。预警提前 15 秒出现。涨水时低地通路关闭，采运暂停，仍在低地的单位沿最近通路退到高地，已部署建筑停止工作至退水。高地一直可走。种子校验保留至少一条高地可达路线。 |

### 四场行动的判定

以下数值为本版验收起点。限时从进入战场开始计算。基础目标完成后可延长 90 秒争取额外目标，延长期满时若指挥员和据点仍在，则按基础成果回归。终局自动回归。

| 行动 | 基础目标 | 额外目标 | 失败条件 |
| --- | --- | --- | --- |
| 工坊守备 | 据点建成后开始接敌。工坊存续满 180 秒，并击退三批指定敌军。 | 达标后运送 25 物资至工坊，带回维修记录。 | 指挥员阵亡、主据点或工坊被毁，或 8 分钟内未达标。 |
| 伏击车队 | 拦截任意一路主运输车，在车停驶位置取回调度器。 | 两辆车都被截停，且从第二处停驶点取回补给清单。 | 指挥员阵亡、已建主据点被毁、两辆主运输车都驶出地图，或 8 分钟内未取回调度器。 |
| 石港立足 | 交付 30 物资修复装卸平台，累计运行 90 秒并击退两次反扑。 | 达标后额外交付 20 物资并完成一次装卸，带回吊运工艺。 | 指挥员阵亡、主据点或平台被毁，或 9 分钟内未达标。 |
| 切断转运 | 占领控制点，向装置供给 40 物资。保护装置累计运行 120 秒并消灭三批反扑部队。 | 从启动断接装置到任务完成，备用机组始终存续。 | 指挥员阵亡、主据点或断接装置被毁，或 10 分钟内未达标。 |

守备类行动在首次满足开战条件时，以及触发后第 45 和 90 秒放出指定敌群，只有两批的行动在前两个时间点放出。主据点、修复平台、启动断接装置分别是三场守备的开战条件。平台与断接装置位于高地，敌军进入目标 5 米内时暂停运行，清除或赶走敌军后恢复。占领控制点需要己方在 5 米内且无敌方单位连续 8 秒。普通巡袭与任务波次分别记录。

伏击车队在入场后第 90 秒和 150 秒进入。出发前标出两条可能路线，车队进入视野后标记实际走向。运输车耐久归零即停驶，目标物留在原地，指挥员靠近后可领取。石港立足完成后，终局据点建成时额外投放 35 物资，限定每次行动一次。任务内的交互、占领和采运进度均用 HUD 明示。

### 建造、敌人和战斗

| 内容 | 本版配置 |
| --- | --- |
| **五类建筑** | 主据点 30 物资，决定可建范围。采运棚 25，绑定一处可达资源点。拒马 10，阻挡通行。机枪座 30，自动攻击。兵营 25，训练机动守军。主据点可修复，修复每次 10 物资，恢复 25% 最大耐久。 |
| **三类友军单位** | 指挥员负责移动、采集和交互。采运员由采运棚配属。守军由兵营训练，每名 15 物资，可以调动并自动接敌。单场最多 12 名守军。 |
| **三类战斗敌人** | 普通兵争夺任务点，快速兵尝试走可达侧路，攻坚兵优先攻击阻挡其前进的工事。另有运输车作为伏击目标。每批任务敌军从 4 名普通兵起，依次加入 2 名快速兵、再加入 1 名攻坚兵。同屏战斗敌人最多 30 名，任务波次超额排队。 |
| **三项局外研究** | 工坊额外目标开放快速维修，使单次修复恢复量提高到 35%。伏击额外目标开放补给标记，开局标出一处最近的可达资源点。石港额外目标开放吊运工艺，使采运棚从每秒采入 2 物资提升到 4。每项首次成功带回后生效。 |
| **两项训练** | 体能训练 50 资金，最大生命提高到 120。侦察训练 75 资金，指挥员视野从 16 米提高到 18 米。每项只购买一次。 |

手采每秒 5 物资。每张地图有 8 至 12 个资源点，每个 30 物资。合法落点附近必须有两处可达资源点和一个可部署主据点的位置。采运棚与手采共用资源库存，采运路线被阻断时暂停产出，重新可达后恢复。主据点 300 耐久。机枪座与守军的初始射程分别为 14 米和 10.5 米，每 0.4 秒最多射击一次，单次基础伤害 3。玩家可以直接调防守军。己方据点、任务点和已标记的接敌通道至少保留一条可达路线。敌军入场后持续推进，触发终局立即冻结对局。若同一步同时发生达标与指挥员阵亡或关键设施被毁，按失败结算。敌军移速及伤害以探索原型的同类敌人为调试起点，按本版四场验收调平。

## 五、结算和反复游玩

- 四场基础目标的首次回归报酬依次为 35、50、55、90 资金。四场额外目标首次回归各给 25 资金，前三场另带回对应研究。已领取的标记和结算一同保存。
- 一般任务达标前允许确认撤回，按放弃结算。阵亡、超时、关键设施被毁和主动放弃都清空本局未结算成果。已带回的研究和局外资金保留。
- 战役存档记录任务完成、首奖、研究和训练。每次成功回归按唯一局号一次提交相关成果。保存失败时保留结算页，用原局号重试。下一场读取对应标记和新的种子。重玩失败不清除已完成的战役进度。重玩可以补未达成的额外目标，已发放的首奖按同一存档只发一次。
- 新战役可另开档。第一次通关形成完整结局，之后仍可从行动列表重玩已开放行动。每个种子改变落点、资源和可用路线，任务目标及战役关系一致。
- 一次性续战留在特殊任务候选池，本版死亡与据点失守都走失败结算。

## 六、操作、界面与表现

| 场合 | 玩家操作和反馈 |
| --- | --- |
| 出发页 | 选择行动和配装，查看地图条件、基础与额外目标、限时、报酬和战役影响，确认出发。已锁行动显示具体条件。 |
| 移动与调防 | 左键选指挥员或守军，右键移动与调防。滚轮缩放，H 回焦点。HUD 显示任务状态、库存、警报和回归选项。 |
| 采运与交互 | E 采集、取物或操作目标，交互提示写明需持续或按一次。目标失去条件时暂停进度并标明原因。 |
| 建造与训练 | V 打开建造侧栏，左键落位，R 旋转拒马，右键或 Esc 取消预览。侧栏显示成本、施工及非法原因。选中兵营下单训练，支付后进入生产。 |
| 回归与暂停 | 回归按钮写明将带回什么，未达标时显示放弃后果并二次确认。Esc 打开暂停时冻结局时与敌我行动。结算后可回行动列表或重开。 |

故事用四张出发简报、四张结果战报和一张结局页表达。画面保持高位斜俯视。灰原用工坊、田埂和外围运输线，石港用堤岸、装卸设施和明显的潮位标记表现地形。敌方普通、快速、攻坚三类使用统一阵营识别和三种轮廓。正式视觉另提交实景预览确认。

## 七、交付边界和验收

交付范围是 Unity 编辑器内的单人键鼠版，包含 **2 个世界、4 场行动、5 类建筑、3 类友军、3 类战斗敌人、1 类任务载具、3 项研究和 2 项训练**。战役使用独立档案，和旧探索、六波守城试玩入口并存。验收先用临时几何表现。触屏、正式美术和设备构建各自另定版本。

| 验收项 | 通过条件 |
| --- | --- |
| 一条完整战役 | 从新档完成第 1、2、4 场，看到结局并能重玩。另走包含第 3 场的路线，确认终局恰好投放一次额外补给。 |
| 两种开局 | 同一种子分别选采运与守备配置，均可完成工坊守备，首笔支出和第一波后的压力有可辨认的差异。再用第二个种子复验。 |
| 世界差异 | 石港涨水预告可读，敌我均受影响，低地采运暂停且退水恢复，高地始终有合法通路。灰原能从外围采运与防线之间作出取舍。 |
| 四种任务 | 守住工坊、截停任一路车队、修复平台及切断转运均可正常达标。任务波次、占领、进度暂停、终局自动回归分别核对。 |
| 回归与存档 | 覆盖基础达标后主动回归、达标前放弃、超时、死亡与达标同一步、成功后重玩。首奖、科技、开放标记与额外补给不会因重试重复提交。 |
| 阅读与操作 | 从 Boot 连续打完四场。玩家能从出发页说清自己为什么参战、怎么回来，并在结算页说清这一仗改变了什么。 |

实施顺序按「派遣与结算 → 灰原两场 → 石港地形与两场任务 → 战报和整局验收」推进。方案确认后按开发规程登记版本与范围，再开展实现。
