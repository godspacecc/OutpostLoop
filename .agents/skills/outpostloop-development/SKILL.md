先读仓库 `AGENTS.md` 和 `Docs/Codex Game Studios 接入.md`，再从 `Docs/执行总清单.md` 定位当前里程碑、确认版本、已有证据和下一项可验收任务。只读与当前任务有关的方案和岗位资料。使用接入文档里的路径映射与适用条件解释上游技能。

1. 对照确认范围选择下一项能实际游玩的任务，复用现有实现并记录可观察的验收条件。新玩法或变更玩法按项目规则送审。已有充分授权的工作直接推进。
2. 按任务调用相关 `cgs-*` 技能。设计、关卡、美术、Unity 和 QA 的岗位资料按需查阅。主代理负责整体推进和最终核验。
3. 沿真实入口实现和验证。测试失败时定位、修复、复跑，直到本批验收条件满足或出现需要用户处理的阻塞。用 `cgs-test-evidence-review` 的方法区分规则测试、输入注入、加速模拟和实际键鼠试玩。
4. 归档本批证据，更新执行总清单中的状态、未覆盖的验收项和下一步。后续授权任务继续执行到交付条件满足。正式视觉评审与超出已确认范围的决定集中给用户看可评审的结果。

Windows 安装包交付按目标平台做本地验收。公开发行与持续运营技能用于对应的发行目标和上线后任务。Player Build、公开发布与正式视觉采用遵循实际授权。
